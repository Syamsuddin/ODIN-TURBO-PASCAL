• Menjelaskan gagasan pemrograman berorientasi objek: objek menyatukan data (field) dan perilaku (method).
  • Mendeklarasikan class, membuat objek dengan Create, dan membebaskannya dengan Free.
  • Menulis constructor dan destructor sendiri, lengkap dengan inherited.
  • Melindungi data dengan private, protected, public, dan property.
  • Menurunkan class dari class lain (pewarisan) dan memakai method virtual, override, dan abstract (polimorfisme).
  • Memakai class var, class function, class of, is, as, dan overload.
  • Menyimpan objek dalam TObjectList dan TStringList, lalu merangkai semuanya dalam program kasir toko.

Sejak Bab 9 Anda memecah program menjadi prosedur dan fungsi, dan sejak Bab 13 Anda mengelompokkan data dalam record. Keduanya masih hidup terpisah: record hanya berisi data, sedangkan prosedur yang mengolahnya ditulis di tempat lain. Pemrograman berorientasi objek (object-oriented programming, OOP) menyatukan keduanya. Sebuah objek membawa datanya sendiri sekaligus tahu cara mengolah data itu. Bab ini memakai sembilan program dari menu File ▸ Examples - OOP..., dari class pertama sampai program kasir toko yang utuh.

Mengapa Objek?

Bayangkan sebuah remote televisi. Anda tidak perlu tahu rangkaian listrik di dalamnya; cukup menekan tombol volume atau kanal. Remote itu menyimpan keadaannya sendiri (kanal yang sedang aktif, besar suara) dan menyediakan tombol untuk mengubahnya. Objek dalam program bekerja dengan cara yang sama: ia menyimpan data dan menyediakan perintah untuk mengolah data itu. Bagian program lain cukup "menekan tombolnya".

1Enkapsulasi

Data dan prosedur yang mengolahnya dibungkus dalam satu class. Data penting disembunyikan dan hanya bisa diubah lewat pintu yang disediakan.

2Pewarisan

Class baru dibuat dari class yang sudah ada. Ia mewarisi semua isinya, lalu menambah atau mengubah sebagian.

3Polimorfisme

Satu perintah yang sama, misalnya Luas, dijalankan dengan cara berbeda menurut jenis objeknya: lingkaran, persegi, atau segitiga.

Ketiga ide ini sering disebut tiga pilar OOP. Setiap pilar punya program contohnya sendiri di bab ini.

Turbo Pascal 7 dan class. Turbo Pascal 7 sudah mengenal OOP lewat kata object. Odin Turbo Pascal memakai bahasa TP7 secara bawaan, lalu memperluasnya dengan class gaya Delphi dan Free Pascal, yaitu bentuk OOP yang dipakai Pascal modern. Program TP7 lama tetap terkompilasi seperti biasa: kata seperti class, property, atau override hanya menjadi kata kunci di tempat yang memang tidak mungkin berisi nama variabel. Beberapa fitur Delphi belum tersedia, yaitu exception (try..except), interface, generics, procedure of object, dan variabel Result. Overload hanya berlaku untuk method.

Class dan Objek Pertama

Class adalah cetakan, dan objek adalah benda yang dicetak darinya. Satu cetakan kue bisa menghasilkan banyak kue; satu class TKucing bisa menghasilkan banyak objek kucing, masing-masing dengan nama dan umurnya sendiri. Class ditulis di bagian type, mirip record, tetapi selain field ia juga memuat header method, yaitu prosedur dan fungsi milik class itu.

type
  TNamaClass = class
    Field1: Tipe;                { data milik setiap objek }
    procedure Method1;          { hanya header }
    function Method2: Tipe;
  end;

procedure TNamaClass.Method1;   { badan method: nama class, titik, nama method }
begin
  ...
end;

Nama class lazim diawali huruf T (dari type), seperti TKucing, TLampu, atau TRekening. Badan method ditulis sesudah deklarasi tipe, dengan nama class di depan nama method. Buka oop_01_class_pertama.pas lewat File ▸ Examples - OOP....

Constructor dan Destructor

Objek yang baru dibuat semua field-nya nol. Sering kali kita ingin objek langsung siap pakai, misalnya lampu yang sudah tahu letaknya. Untuk itu class boleh punya constructor sendiri, yaitu method khusus yang dijalankan saat objek dibuat. Pasangannya, destructor, dijalankan tepat sebelum memori objek dikembalikan. Destructor sebuah class selalu bernama Destroy dan ditandai override, karena ia menggantikan Destroy milik TObject.

Pewarisan

Mobil dan sepeda sama-sama kendaraan: keduanya punya merek dan jumlah roda. Daripada menulis field yang sama dua kali, kita buat class umum TKendaraan, lalu menurunkan TMobil dan TSepeda darinya. Polimorfisme: virtual, override, abstract

Lingkaran, persegi, dan segitiga sama-sama bangun datar, dan semuanya punya luas. Rumusnya saja yang berbeda. Kita ingin menyimpan ketiganya dalam satu larik bertipe TBangun, lalu cukup menulis Bangun[I].Luas, dan setiap bangun menghitung luasnya dengan rumusnya sendiri. Kemampuan inilah yang disebut polimorfisme ("banyak bentuk").

Kuncinya ada pada tiga kata. Method virtual dipilih saat program berjalan menurut class objek yang sebenarnya, bukan menurut tipe variabelnya. Turunan menggantinya dengan override. Method abstract tidak punya badan sama sekali: induk hanya berjanji bahwa method itu ada, dan setiap turunan wajib mengisinya.

Class Var, Class Method, dan class of

Field biasa dimiliki setiap objek: tiap kucing punya namanya sendiri. Kadang kita butuh satu data untuk seluruh class, misalnya jumlah hewan yang sedang hidup. Itulah class var. Dengan cara yang sama, class function adalah method yang dipanggil lewat nama class tanpa perlu membuat objek, misalnya TAnjing.Suara.

Tipe class of lebih unik lagi: variabelnya tidak menyimpan objek, melainkan sebuah class. Program bisa memilih class mana yang akan dibuat saat berjalan, misalnya menurut pilihan pengguna. Agar constructor milik class terpilih yang dijalankan, constructor induknya harus virtual.

Overload

Kadang ada beberapa cara wajar untuk membuat objek yang sama. Waktu bisa dibuat dari jam dan menit, dari total menit, atau sebagai 00:00. Dengan overload, beberapa method boleh memakai nama yang sama asalkan daftar parameternya berbeda. Kompiler memilih versi yang paling cocok dengan argumen yang diberikan. Di Odin Turbo Pascal, overload hanya berlaku untuk method, tidak untuk prosedur dan fungsi biasa.

Kesalahan yang Sering Terjadi

Memakai objek sebelum dibuat. Variabel class yang belum diisi Create belum menunjuk objek apa pun. Mengisi field-nya sama dengan mengikuti pointer nil di Bab 18.

program lupa_create; type TKucing = class Nama: String; end; var Kucing: TKucing; begin Kucing.Nama := 'Belang'; WriteLn(Kucing.Nama); end.

Mengubah property hanya-baca. Property tanpa write ditolak kompiler bila diberi nilai.

program saldo; type TRekening = class private FSaldo: LongInt; public property Saldo: LongInt read FSaldo; end; var R: TRekening; begin R := TRekening.Create; R.Saldo := 1000000; R.Free; end.

Menulis virtual padahal maksudnya override. Method di turunan yang ditandai virtual lagi tidak menggantikan method induk, melainkan menyembunyikannya. Program tetap terkompilasi dengan peringatan, tetapi polimorfismenya hilang: anjing bersuara ....

program lupa_override; type THewan = class function Suara: String; virtual; end; TAnjing = class(THewan) function Suara: String; virtual; end; function THewan.Suara: String; begin Suara := '...'; end; function TAnjing.Suara: String; begin Suara := 'guk guk'; end; var H: THewan; begin H := TAnjing.Create; WriteLn(H.Suara); H.Free; end.

Membuat objek dari class abstrak. Kompiler mengizinkan TBangun.Create, tetapi memanggil method abstraknya menghentikan program dengan runtime error 211. Buatlah objek dari class turunan yang sudah mengisi semua method abstrak.

program abstrak; type TBangun = class function Luas: Real; virtual; abstract; end; var B: TBangun; begin B := TBangun.Create; WriteLn(B.Luas:0:2); B.Free; end.

Memakai as tanpa memeriksa. Bila objeknya ternyata bukan class yang diminta, as menghentikan program. Periksa dulu dengan is bila jenisnya belum pasti.

program salah_as; type TBarang = class Judul: String; end; TBuku = class(TBarang) Halaman: Integer; end; TMajalah = class(TBarang) Edisi: String; end; var X: TBarang; begin X := TMajalah.Create; WriteLn((X as TBuku).Halaman); X.Free; end.

Lupa overload. Dua method bernama sama tanpa tanda overload dianggap nama ganda.

program tanpa_overload; type TWaktu = class Jam: Integer; procedure Tambah(M: Integer); procedure Tambah(Lain: TWaktu); end; procedure TWaktu.Tambah(M: Integer); begin Jam := Jam + M div 60; end; procedure TWaktu.Tambah(Lain: TWaktu); begin Jam := Jam + Lain.Jam; end; begin end.
  • Lupa membebaskan objek. Setiap Create butuh pasangan Free, kecuali objek yang dimiliki TObjectList. Memori yang tidak dibebaskan baru kembali saat program selesai.
  • Membebaskan objek dua kali, misalnya lewat dua rujukan ke objek yang sama seperti Kucing dan Sama di Program 21.1.
  • Lupa inherited di constructor dan destructor. Bagian milik induk tidak disiapkan atau tidak dibereskan.
  • Menulis inherited Destroy di awal destructor. Panggil di akhir, setelah bagian milik class sendiri dibereskan.

Rangkuman

  • Class adalah cetakan yang menyatukan field (data) dan method (perilaku); objek dibuat darinya dengan Create dan dibebaskan dengan Free.
  • Variabel class menyimpan rujukan. Penugasan antarvariabel class menyalin rujukan, bukan objeknya.
  • Constructor menyiapkan objek, destructor Destroy (dengan override) membereskannya. Keduanya memanggil versi induk lewat inherited.
  • private, protected, dan public mengatur siapa boleh memakai anggota class; property membuka data lewat read dan write yang bisa diperiksa.
  • Pewarisan (class(TInduk)) membuat class baru dari class lama; semua class berakar pada TObject.
  • Polimorfisme: method virtual dipilih menurut class objek saat program berjalan; turunan menggantinya dengan override; method abstract wajib diisi turunan.
  • class var dan class function milik class, bukan objek; class of menyimpan class yang dipilih saat berjalan.
  • is memeriksa jenis objek, as memakainya sebagai class tertentu dengan pemeriksaan (galat 219 bila salah).
  • overload membolehkan beberapa method bernama sama dengan parameter berbeda.
  • TObjectList (unit Contnrs) dan TStringList (unit Classes) menyimpan daftar objek dan string dengan indeks mulai 0.
