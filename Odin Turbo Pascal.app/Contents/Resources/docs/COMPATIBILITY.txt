TOOLCHAIN ODIN (SATU-SATUNYA COMPILER SESUDAH 2.3.0)

Compiler adalah toolchain Odin: compiler odinpc (Rust, tanpa crate pihak
ketiga) dengan assembler, linker, dan debugger sendiri, serta runtime library
sendiri di rtl/. Target: x86_64-darwin, aarch64-darwin (Mach-O dengan tanda
tangan kode ad-hoc yang diwajibkan macOS di Apple Silicon), x86_64-linux dan
aarch64-linux (ELF dinamis, glibc 2.34 atau lebih baru), x86_64-windows
(PE32+ dengan kernel32 dan UCRT). Di sistem lain (misalnya Windows on ARM)
IDE bisa mengedit tetapi tidak mengompilasi.
Sampai 2.3.0, Free Pascal bisa dipilih sebagai backend alternatif (dengan
mode ObjFPC/Delphi dan Free Vision). Backend itu sudah dicabut; program
ObjFPC/Delphi tidak lagi didukung.

Diuji 15 Oktober 2026 pada Mac Intel x86_64 (Darwin 24.6) dengan FPC 3.2.2
sebagai pembanding: kesepuluh contoh, 77 program uji diferensial, dan layar
Crt (jendela, scroll, warna) memberi hasil yang sama. Korpus yang sama juga
lulus di VM Ubuntu 24.04 (x86_64, dan aarch64 lewat qemu-user) dan di runner
GitHub Actions untuk macOS 15 Apple Silicon, Ubuntu 24.04 x86_64, dan Ubuntu
24.04 arm64, bersama tes IDE, debugger, dan Odin Vision.
Di runner Windows Server 2025, korpus dibandingkan dengan keluaran Free Pascal
3.2.2 untuk Windows (i386-win32), juga bersama tes IDE, debugger, dan Odin
Vision. Mac Apple Silicon, PC Linux, dan PC Windows fisik belum diuji
langsung.

Di Windows, berkas teks memakai CRLF (WriteLn menulis CRLF seperti di DOS),
path memakai '\' dan huruf drive, Exec memakai _spawnvpe, dan Printer
mencetak lewat notepad /p. User screen IDE memakai ConPTY, dan debugger
berbicara dengan program lewat TCP 127.0.0.1.

Di arm64, prosesor tidak menghentikan program saat operasi real gagal.
Kode hasil kompilasi membaca bendera FPSR sesudah operasi real dan
menghasilkan runtime error 207, 200, atau 205 seperti di x86-64.

Unit Odin: System, Crt, Dos, Strings, Printer, Objects, dan Odin Vision
(Turbo Vision milik Odin): Drivers, Memory, HistList, Views, Menus, Validate,
Dialogs, App, MsgBox, StdDlg, Editors, Outline, ColorSel, TextView. Tipe
object TP7 didukung.
Ekspektasi uji dibuat dengan Free Pascal 3.2.2 sebagai pembanding sampai
2.3.0; perbedaan yang disengaja dicatat di tests/pascal/DEVIATIONS.md.

Odin Vision mengikuti API Turbo Vision TP7, tetapi tampilan dan beberapa
detailnya milik Odin sendiri (rincian di rtl/vision/SPEC.md):
- Warna palet dirancang sendiri. Tata letak indeks palet sama dengan TP7.
- Ukuran data dialog mengikuti TP7: check box dan radio button 2 byte,
  TMultiCheckBoxes 4 byte, input line MaxLen+1. TListBoxRec 16 byte dan
  parameter TParamText/FormatStr berukuran PtrInt (8 byte). Record biasa
  disejajarkan, jadi record data dialog harus packed record.
- Dialog berkas memakai path macOS ('/'), menyembunyikan nama berawalan
  titik, dan menerima nama sampai 255 karakter (datanya PathStr).
- Editor menyimpan akhir baris apa adanya; Enter menyisipkan LF. Undo hanya
  satu langkah, seperti TP. Pasang EditorDialog := StdEditorDialog supaya
  editor bisa bertanya "simpan?".
- Pesan validator, judul MessageBox, dan label tombol bawaan berbahasa
  Inggris, seperti Turbo Vision.
- Ukuran layar mengikuti terminal (di User screen 80x25). Mouse berjalan di
  User screen dan di terminal yang mendukung laporan mouse SGR (xterm,
  Terminal.app, iTerm2). Alt+huruf dikirim sebagai Esc + huruf; di User
  screen macOS, Option dipakai sebagai Alt (tata letak keyboard US). Option
  pada keyboard Mac sungguhan belum diuji, hanya dengan event sintetis.
- Memory tidak membatasi heap: LowMemory selalu False. DosShell menjalankan
  $SHELL.
- ColorSel dan TextView mengikuti API TP7, termasuk daftar item standar TV2
  (DesktopColorItems, MenuColorItems, DialogColorItems, WindowColorItems),
  ColorIndexes, dan registrasi stream ColorSel. TTerminal memakai buffer
  melingkar: bila penuh, baris teratas dibuang. WriteLn ke berkas yang dipasang
  dengan AssignDevice langsung tampil di jendelanya; CR dibuang dan Tab menjadi
  kelipatan 8 kolom. Tampilan dialog warna rancangan Odin sendiri.

Executable hasil Odin memuat runtime library Odin, yang berlisensi
GNU GPL v3 atau yang lebih baru tanpa pengecualian runtime. Bila executable
itu dibagikan, ketentuan GPL berlaku untuk executable tersebut.

               Exclude, IOResult, ExitProc.
Crt            Tersedia. ClrScr, GotoXY, WhereX/WhereY, warna, Window, ClrEol,
               DelLine, Delay, Sound/NoSound, KeyPressed, ReadKey, termasuk

               dan TextView.

Fitur era DOS yang tidak dapat dikompilasi di sistem 64-bit: Mem/MemW/MemL,
Port, absolute $Seg:$Ofs, PrefixSeg, MemAvail/MaxAvail, Test8087, inline(...),
procedure interrupt, serta Intr/MsDos/Registers. Blok asm belum didukung.
GetIntVec/SetIntVec dan Keep dapat dikompilasi tetapi tidak berefek:
GetIntVec mengembalikan nil dan Keep tidak menghentikan program. CSeg/DSeg/
SSeg bernilai 0.

Perbedaan perilaku yang perlu diperhatikan:
- Real berukuran 8 byte (TP: 6 byte), dan Real48 tidak tersedia. Berkas biner
  berisi Real dari TP perlu dikonversi lebih dahulu.
- Pointer berukuran 8 byte. Integer tetap 2 byte dan LongInt 4 byte.
- Round memakai pembulatan ke genap: Round(2.5)=2, Round(-2.5)=-2. Periksa
  program yang bergantung pada pembulatan nilai .5.

Bundel macOS membawa odinpc universal (x86_64 dan arm64); odinpc membuat
program untuk CPU Mac yang menjalankannya. Interpreter launcher dan source
Python sama untuk kedua CPU. Ini berbeda dari binary universal2 yang
membundel semua runtime ke satu aplikasi mandiri.

Pemeriksaan akhir di Mac yang masih diperlukan, di Mac bersih tanpa Free
Pascal dan tanpa Xcode Command Line Tools:
1. Jalankan Install.command pada Intel dan Apple Silicon.
2. Pastikan pemeriksaan compile/run native dengan odinpc berhasil pada kedua
   chip.
3. Buka .app dari Finder, tutup, buka kembali, dan uji Open With untuk .pas.
4. Uji Fn+F1..F12, Command shortcuts, clipboard, dialog, dan display Retina.
5. Run bab04_02_read_readln.pas dan bab19_02_unit_crt.pas, uji debugger
   (breakpoint, Watch, Call stack), lalu demo Odin Vision.
6. Uji izin Privacy & Security, Gatekeeper, pembaruan app, dan Uninstall.

Hasil Linux dan runner CI tidak menggantikan enam pemeriksaan macOS tersebut.
