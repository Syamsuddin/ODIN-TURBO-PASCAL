• Memahami guna tipe data dan cara memilih tipe yang tepat.
  • Memakai tipe bilangan (Integer, LongInt, Real), karakter (Char, string), dan Boolean.
  • Mengubah antar-tipe dengan Trunc, Round, Ord, dan Chr.
  • Membedakan variabel dari konstanta.
  • Mengetahui ukuran dan rentang setiap tipe, serta apa yang terjadi bila nilai melampauinya.

Setiap data yang disimpan program punya jenis: bilangan bulat, bilangan pecahan, satu huruf, sepotong teks, atau nilai benar/salah. Jenis itu disebut tipe data. Memilih tipe yang tepat membuat program benar, hemat memori, dan mudah dibaca. Bab ini mengenalkan tipe-tipe dasar yang akan Anda pakai di sepanjang buku.

Variabel dan Tipenya

Sebuah variabel adalah tempat bernama di memori untuk menyimpan nilai yang bisa berubah. Sebelum dipakai, variabel harus diumumkan di bagian var beserta tipenya. Tipe menentukan tiga hal: nilai apa yang boleh disimpan, berapa besar memori yang dipakai, dan operasi apa yang berlaku.

var
  namaVariabel: Tipe;
  namaLain, namaLagi: Tipe;   { beberapa nama bertipe sama }

Bayangkan variabel sebagai kotak berlabel. Labelnya adalah nama, isinya adalah nilai, dan bentuk kotaknya adalah tipe, yang menentukan isi macam apa yang muat.

Bilangan: Integer dan Real

Ada dua kelompok bilangan. Bilangan bulat (tanpa pecahan) disimpan dengan tipe seperti Integer dan LongInt. Bilangan pecahan (dengan koma) disimpan dengan Real. Di Pascal, pemisah desimal adalah titik, bukan koma: tulis 165.5, bukan 165,5.

Dalam mode Turbo Pascal, Integer berukuran 2 byte dengan rentang −32768 sampai 32767. Untuk bilangan yang lebih besar, misalnya jumlah penduduk, pakai LongInt (4 byte, sampai sekitar 2 miliar). Memberi nilai di luar rentang akan memicu kesalahan, bukan menghasilkan angka yang salah diam-diam.

Dua hal penting dari program ini. Pertama, pembagian dengan / selalu menghasilkan Real, walau kedua angkanya bulat: 100 / 32 memberi 3.1250, bukan 3. Kedua, bilangan Real ditampilkan dengan format :lebar:desimal. TinggiBadan:0:1 berarti "lebar secukupnya, satu angka di belakang titik". Tanpa format, Real tampil dalam notasi ilmiah yang sulit dibaca, jadi selalu format setiap Real saat ditampilkan.

Perhatikan juga perubahan antar-tipe di akhir program. Integer boleh langsung dimasukkan ke Real (baris 30), tetapi sebaliknya tidak: Real harus diubah dulu. Trunc membuang bagian pecahan (165.9 menjadi 165), sedangkan Round membulatkan ke bilangan terdekat (165.9 menjadi 166).

Teks: Char dan String

Tipe Char menyimpan tepat satu karakter, sedangkan string menyimpan deretan karakter. Teks ditulis di antara tanda petik tunggal: 'A' untuk sebuah Char, 'Budi Santoso' untuk sebuah string.

Beberapa ide baru muncul di sini:

  • Panjang string dibatasi. string[9] hanya memuat 9 karakter; kelebihannya dipotong, sehingga 'Kandangan Barat' menjadi 'Kandangan'. string biasa memuat hingga 255 karakter.
  • Setiap karakter punya kode. Ord('A') memberi kode ASCII-nya, 65. Kebalikannya, Chr(66) memberi karakter 'B'. Ord dan Chr saling membalik.
  • Karakter dalam string diambil lewat indeks, mulai dari 1: Nama[1] adalah huruf pertama. Length(Nama) memberi jumlah karakternya.
  • Tanda + menyambung string. Untuk menulis tanda petik di dalam teks, ketik dua kali: 'Jum''at' menghasilkan Jum'at.

Dalam mode Turbo Pascal, string adalah short string: panjang maksimumnya 255 karakter, dan karakter pertamanya (indeks 1) adalah isi sesungguhnya. Bab 12 membahas pengolahan string lebih dalam.

Benar atau Salah: Boolean

Tipe Boolean hanya punya dua nilai: True (benar) dan False (salah). Tipe ini tampak sederhana, tetapi menjadi dasar semua pengambilan keputusan di Bab 6. Hasil sebuah perbandingan, seperti Umur >= 17, adalah nilai Boolean yang bisa disimpan dan dipakai ulang.

Variabel Boolean ditampilkan sebagai TRUE atau FALSE. Yang menarik, variabel Boolean bisa langsung dipakai sebagai syarat if tanpa perbandingan tambahan: if SudahDewasa then sudah cukup. Operator not membalik nilainya, sehingga not Hujan bernilai True ketika Hujan bernilai False.

Konstanta

Kadang sebuah nilai memang tidak boleh berubah selama program berjalan: harga satuan, nilai pi, nama toko. Nilai seperti itu sebaiknya diberi nama lewat konstanta di bagian const. Keuntungannya dua: program lebih mudah dibaca (Diskon lebih jelas daripada angka 0.10 yang berserakan), dan bila nilainya perlu diganti, cukup ubah di satu tempat.

const
  NamaKonstanta = nilai;   { pakai = , bukan := }

Perbedaan penting dari variabel: konstanta memakai tanda = (bukan :=) saat diumumkan, dan nilainya tidak bisa diubah setelah itu. Mencoba menugaskan nilai baru ke konstanta akan ditolak kompiler:

program Toko; const Harga = 45000; begin Harga := 50000; WriteLn(Harga); end.

Ukuran dan Batas Tipe

Setiap tipe menempati sejumlah byte di memori dan punya rentang nilai tertentu. Fungsi bawaan membantu memeriksanya: SizeOf memberi ukuran dalam byte, Low dan High memberi nilai terkecil dan terbesar.

Mengapa batas ini penting? Karena memberi nilai di luar rentang tipe akan menghentikan program. Misalnya sebuah Byte hanya memuat 0 sampai 255; menambah 1 pada 255 melampaui batas, dan program berhenti dengan runtime error 201.

program Luap; var B: Byte; begin B := 255; B := B + 1; WriteLn(B); end.

Range check dan overflow check aktif secara bawaan di kompiler Odin, sehingga kesalahan seperti ini ketahuan langsung, bukan menghasilkan angka yang keliru. Biarkan tetap aktif selama belajar, dan pilih tipe yang rentangnya cukup untuk data Anda, misalnya LongInt untuk uang atau jumlah penduduk.

Rangkuman

  • Tipe data menentukan nilai yang boleh disimpan, ukuran memori, dan operasi yang berlaku. Variabel diumumkan di var beserta tipenya.
  • Integer (2 byte, ±32 ribu) dan LongInt (4 byte, ±2 miliar) untuk bilangan bulat; Real untuk pecahan dengan pemisah titik.
  • Pembagian / selalu menghasilkan Real. Format setiap Real dengan :lebar:desimal saat ditampilkan.
  • Trunc membuang pecahan, Round membulatkan; Ord dan Chr mengubah antara karakter dan kodenya.
  • Char satu karakter, string deretan karakter (maks 255 di mode TP), diambil lewat indeks mulai 1.
  • Boolean bernilai True/False dan bisa langsung menjadi syarat.
  • Konstanta (const, pakai =) menamai nilai tetap yang tidak bisa diubah. Melampaui rentang tipe memicu runtime error 201.

Latihan

  1. DasarBuat program yang menyimpan nama, umur, dan tinggi badan (Real) Anda, lalu menampilkannya rapi. Format tinggi badan dengan satu angka desimal.
  2. DasarTampilkan kode ASCII huruf 'a' sampai 'e' memakai Ord, dan karakter untuk kode 48 sampai 57 memakai Chr.
  3. MenengahHitung dan tampilkan 22 / 7 dengan 2, 4, dan 6 angka desimal memakai format :0:n. Amati perbedaannya.
  4. MenengahSimpan hasil perbandingan Nilai >= 75 ke variabel Boolean bernama Lulus, lalu pakai sebagai syarat if.
  5. TantanganPakai tipe Byte untuk sebuah umur, lalu sengaja beri nilai 300. Jalankan dan jelaskan apa yang terjadi serta mengapa.
