• Memahami syarat (kondisi) sebagai ekspresi Boolean yang bernilai True atau False.
  • Memakai if..then untuk menjalankan perintah hanya bila syaratnya terpenuhi.
  • Memakai if..then..else untuk memilih satu dari dua jalan, dan memahami mengapa tidak boleh ada titik koma sebelum else.
  • Menyusun if bersarang dan rantai else if, serta mengenali jebakan dangling else.
  • Memakai case..of dengan daftar nilai, rentang, dan cabang else.
  • Menerapkan percabangan pada masalah nyata: nilai huruf dan tahun kabisat.

Semua program di bab-bab sebelumnya berjalan lurus: perintah pertama, kedua, ketiga, sampai end., tanpa pernah melompati satu baris pun. Program seperti itu tidak bisa bereaksi terhadap keadaan. Di bab ini Anda akan mengajari program mengambil keputusan: menjalankan sebagian perintah hanya bila suatu syarat terpenuhi, memilih satu dari dua jalan, atau memilih satu dari banyak kemungkinan. Kemampuan inilah yang membuat program terasa "pintar".

Program yang Bisa Memilih

Setiap hari Anda mengambil keputusan dengan pola yang sama: kalau hujan, maka bawa payung. Kalau nilai ujian 75 atau lebih, maka lulus, kalau tidak ikut remedial. Pola "kalau ... maka ... kalau tidak ..." ini disebut percabangan (branching atau selection), karena jalannya program bercabang seperti jalan di persimpangan. Program memeriksa sebuah syarat, lalu memilih cabang mana yang ditempuh.

Di Pascal, syarat adalah ekspresi Boolean: ekspresi yang hasilnya hanya salah satu dari dua nilai, True (benar) atau False (salah). Anda sudah mengenalnya di Bab 5. Syarat biasanya dibentuk dari operator pembanding (=, <>, <, >, <=, >=) dan digabung dengan operator logika and, or, serta not. Pascal menyediakan dua perintah percabangan. Perintah if memeriksa sebuah syarat Boolean dan cocok untuk keputusan "ya atau tidak". Perintah case memeriksa nilai sebuah variabel dan cocok untuk memilih satu dari banyak kemungkinan, misalnya nomor menu atau nama hari. Keduanya akan dibahas satu per satu.

Banyak cabang. Nilai sebuah variabel ordinal dicocokkan dengan label setiap cabang.

Percabangan Satu Arah: if..then

Bentuk paling sederhana adalah if..then. Bila syarat bernilai True, pernyataan sesudah then dijalankan. Bila False, pernyataan itu dilewati begitu saja, dan program langsung melanjutkan ke pernyataan berikutnya. Tidak ada yang dikerjakan sebagai gantinya.

if syarat then
  pernyataan;

if syarat then
begin
  pernyataan1;
  pernyataan2;
end;

Sesudah then hanya boleh ada satu pernyataan. Bila Anda ingin menjalankan beberapa perintah sekaligus, bungkus semuanya dengan begin dan end. Gabungan ini disebut pernyataan majemuk (compound statement): bagi kompiler, seluruh isi begin..end dihitung sebagai satu pernyataan. Perhatikan cara kerja if..then pada diagram alir berikut. Belah ketupat kuning adalah titik keputusan; dari sana ada dua jalan keluar, True dan False.

Dua Pilihan: if..then..else

Sering kali kita tidak hanya ingin melewati perintah, tetapi melakukan hal lain sebagai gantinya: bila genap tulis "genap", bila tidak tulis "ganjil". Untuk itu if dilengkapi bagian else (artinya "kalau tidak"). Dengan if..then..else, tepat satu dari dua cabang selalu dijalankan: cabang then bila syarat True, cabang else bila False. Tidak mungkin keduanya dijalankan, dan tidak mungkin keduanya dilewati.

if syarat then
  pernyataan_bila_True
else
  pernyataan_bila_False;

Perhatikan baik-baik: tidak ada titik koma sebelum else. Titik koma di Pascal adalah pemisah antar pernyataan. Seluruh if..then..else adalah satu pernyataan, jadi titik koma baru boleh ditulis setelah cabang else selesai. Bila Anda menulis titik koma sebelum else, kompiler mengira pernyataan if sudah berakhir, lalu bingung menemukan else yang tidak punya pasangan.

Program 6.2 memakai if..then..else dua kali. Yang pertama menentukan genap atau ganjil dengan operator mod (sisa bagi). Yang kedua memutuskan kelulusan, dan setiap cabangnya berisi pernyataan majemuk.

Bilangan 7 dibagi 2 bersisa 1, jadi syarat baris 15 False dan cabang else pada baris 18 yang dijalankan. Nilai 60 kurang dari 75, jadi blok else pada baris 28–31 dijalankan dan baris 30 menghitung kekurangannya, 75 - 60. Sekarang coba masukan yang menempuh cabang lainnya: bilangan genap dan nilai tepat 75.

if Bersarang dan Rantai else if

Cabang sebuah if boleh berisi pernyataan apa saja, termasuk if lain. if di dalam if ini disebut if bersarang (nested if). Ada dua pola yang sangat sering dipakai:

  • Rantai else if: if baru ditaruh di cabang else. Hasilnya adalah deretan syarat yang diperiksa dari atas ke bawah, dan berhenti di syarat pertama yang True. Pola ini dipakai untuk memilih satu dari beberapa kelompok, misalnya kelompok umur.
  • if di dalam then: pertanyaan kedua hanya diajukan bila jawaban pertama True, misalnya "apakah pelajar?" hanya ditanyakan kepada pengunjung berumur 13 sampai 22 tahun.
if syarat1 then
  pernyataan1
else if syarat2 then
  pernyataan2
else if syarat3 then
  pernyataan3
else
  pernyataan_bila_semua_False;

Sebenarnya Pascal tidak punya kata else if. Yang terjadi adalah cabang else berisi sebuah pernyataan if baru, yang cabang else-nya berisi if baru lagi, dan seterusnya. Karena penulisannya menjadi rapi seperti daftar, programmer menyebutnya rantai else if. Diagram berikut memperlihatkan rantai dari Program 6.3, yang menentukan harga tiket berdasarkan umur.

Jebakan else yang Menggantung

Ketika if bersarang tanpa begin..end, muncul pertanyaan: sebuah else milik if yang mana? Aturan Pascal tegas: else selalu menjadi pasangan if terdekat di atasnya yang belum punya else. Indentasi tidak berpengaruh sama sekali. Masalah ini terkenal dengan nama dangling else (else yang menggantung). Program berikut ditulis dengan indentasi yang menipu: penulisnya ingin else menjadi milik if Umur >= 13.

program Gantung; var Umur: Integer; Pelajar: Char; begin Umur := 17; Pelajar := 'T'; if Umur >= 13 then if Pelajar = 'Y' then WriteLn('Dapat potongan pelajar') else WriteLn('Anak-anak tidak perlu kartu pelajar'); WriteLn('Selesai.'); end.

Program ini lolos kompilasi, tetapi hasilnya salah. Kompiler membaca baris 11 sebagai else milik if Pelajar = 'Y' (baris 9), karena itulah if terdekat yang belum punya else. Akibatnya, remaja yang bukan pelajar disebut anak-anak. Cara memperbaikinya adalah membungkus if bagian dalam dengan begin..end, sehingga if itu tertutup sebelum else dibaca.

✗Indentasi menipu

if Umur >= 13 then if Pelajar = 'Y' then WriteLn('Potongan pelajar') else WriteLn('Anak-anak');

else menempel pada if Pelajar = 'Y'.

✓Batas yang jelas

if Umur >= 13 then begin if Pelajar = 'Y' then WriteLn('Potongan pelajar'); end else WriteLn('Anak-anak');

end menutup if dalam; else milik if Umur >= 13.

Banyak Pilihan: case..of

Bayangkan program yang mengubah nomor hari 1 sampai 7 menjadi nama hari. Dengan if, Anda butuh rantai tujuh syarat NomorHari = 1, NomorHari = 2, dan seterusnya. Pascal menyediakan cara yang lebih ringkas: case..of. Nilai sebuah ekspresi, yang disebut selektor, dicocokkan dengan label setiap cabang. Cabang yang labelnya cocok dijalankan, sisanya dilewati. Cara kerjanya seperti lift: Anda menekan tombol lantai, dan lift langsung berhenti di lantai itu tanpa perlu bertanya "lantai 1? lantai 2?" satu per satu.

case selektor of
  label1: pernyataan1;
  label2, label3: pernyataan2;        { daftar nilai }
  awal..akhir: pernyataan3;             { rentang nilai }
else
  pernyataan_bila_tidak_ada_yang_cocok;
end;

Satu cabang boleh berlaku untuk beberapa nilai. Tulis nilai-nilai itu dipisah koma (1, 7) atau sebagai rentang dengan dua titik (2..6, artinya 2 sampai 6). Contoh pengelompokan pada case kedua Program 6.4 tampak seperti ini: nilai 1 dan 7 masuk cabang libur, nilai 2 sampai 6 masuk cabang sekolah.

program Vokal; var Huruf: Char; begin Huruf := 'K'; case Huruf of 'A', 'I', 'U', 'E', 'O': WriteLn('Huruf vokal'); 'B'..'Z': WriteLn('Huruf konsonan'); end; end.

Selektor case harus bertipe ordinal, yaitu tipe yang nilainya bisa diurutkan dan dihitung satu per satu: Integer, LongInt, Char, Boolean, enumerasi, dan subrange. Tipe Real dan String tidak boleh menjadi selektor. Label harus berupa konstanta yang sudah diketahui saat kompilasi, bukan variabel. Untuk memilih berdasarkan teks atau bilangan pecahan, pakailah rantai else if.

pilihan bergantung pada nilai satu variabel ordinal yang bisa didaftar: nomor menu, nomor bulan, huruf jawaban, atau kelompok rentang angka bulat.

Kesalahan yang Sering Terjadi

Titik koma sebelum else

Ini kesalahan percabangan nomor satu bagi pemula. Program berikut menulis titik koma di akhir baris 7, tepat sebelum else. Di Odin Turbo Pascal, kompilasi yang gagal membuka jendela Compile failed, dan baris tempat kompiler tersandung ditandai merah.

program Genap; var N: Integer; begin N := 7; if N mod 2 = 0 then WriteLn('Genap'); else WriteLn('Ganjil'); end.

Kompiler menunjuk baris 8, tempat else berada, padahal penyebabnya ada di akhir baris 7. Titik koma itu menutup pernyataan if, sehingga kata else sesudahnya menjadi awal pernyataan baru, dan tidak ada pernyataan Pascal yang diawali else. Perbaikannya: hapus titik koma di akhir baris 7.

Titik koma sesudah then

Kebalikan dari kesalahan di atas jauh lebih berbahaya, karena kompiler tidak menolaknya. Titik koma tepat sesudah then membuat cabang if berisi pernyataan kosong. Perintah pada baris berikutnya tidak lagi menjadi bagian dari if, sehingga selalu dijalankan.

program Demam; var Suhu: Integer; begin Suhu := 36; if Suhu >= 38 then; WriteLn('Anda demam. Istirahatlah.'); WriteLn('Pemeriksaan selesai.'); end.

Indentasi baris 7 membuatnya tampak berada di dalam if, tetapi titik koma di akhir baris 6 sudah menutup if itu. Kesalahan logika seperti ini hanya bisa ditemukan dengan menguji program memakai data yang hasilnya sudah Anda ketahui. Hal yang sama berlaku untuk else;.

case tanpa end

Setiap case harus ditutup end. Karena case tidak diawali begin, end ini mudah terlupa, terutama bila case berada di akhir program.

program Hari; var N: Integer; begin N := 3; case N of 1: WriteLn('Minggu'); 2: WriteLn('Senin'); 3: WriteLn('Selasa'); end.

Kata end pada baris 10 dipakai kompiler untuk menutup case. Akibatnya begin pada baris 4 tidak punya pasangan, dan titik sesudahnya muncul di tempat yang tidak terduga. Pesan kesalahan seperti ini sering membingungkan karena menunjuk baris terakhir. Bila kompiler mengeluh tentang akhir program, periksa apakah setiap case dan setiap begin sudah punya end.

Lupa tanda kurung pada syarat gabungan

program Rentang; var Nilai: Integer; begin Nilai := 105; if Nilai < 0 or Nilai > 100 then WriteLn('Nilai tidak sah'); end.

Karena or dikerjakan lebih dulu daripada < dan >, kompiler membaca baris 6 sebagai Nilai < (0 or Nilai) > 100, sesuatu yang tidak masuk akal. Tulislah setiap perbandingan di dalam kurung: (Nilai < 0) or (Nilai > 100).

Rangkuman

  • Percabangan membuat program memilih jalan berdasarkan syarat, yaitu ekspresi Boolean yang bernilai True atau False.
  • if..then menjalankan satu pernyataan bila syarat True. Untuk beberapa perintah, bungkus dengan begin..end (pernyataan majemuk).
  • if..then..else selalu menjalankan tepat satu dari dua cabang. Tidak ada titik koma sebelum else; titik koma sesudah then membuat cabang kosong.
  • Rantai else if memeriksa syarat dari atas ke bawah dan berhenti di syarat pertama yang True, jadi urutan syarat penting.
  • else selalu milik if terdekat yang belum punya else (dangling else); gunakan begin..end untuk memperjelas.
  • case..of memilih cabang berdasarkan nilai selektor ordinal. Label boleh berupa daftar (1, 7) atau rentang (2..6), tidak boleh bertumpuk, dan case selalu ditutup end.
  • Dalam syarat gabungan, beri kurung pada setiap perbandingan; and dikerjakan sebelum or.
  • Uji program percabangan dengan satu masukan untuk setiap cabang, termasuk nilai-nilai batas.

Latihan

  1. DasarBuat program yang membaca sebuah bilangan bulat, lalu menulis positif, negatif, atau nol.
  2. DasarUbah Program 6.1 agar suhu 35 sampai 37 menampilkan Suhu normal. Gunakan rantai else if sehingga hanya satu pesan suhu yang mungkin muncul.
  3. MenengahBaca tiga bilangan bulat, lalu tampilkan yang terbesar. Uji dengan masukan yang terbesarnya di posisi pertama, kedua, dan ketiga, serta dengan tiga bilangan yang sama.
  4. MenengahBuat program nomor bulan 1–12 yang menampilkan nama bulan dan jumlah harinya. Gunakan case dengan daftar nilai untuk bulan 30 dan 31 hari. Untuk Februari, tanyakan tahunnya dan pakai aturan kabisat dari Program 6.6.
  5. MenengahBuat kalkulator sederhana: baca dua bilangan dan sebuah operator Char (+, -, *, /), lalu hitung dengan case. Tolak pembagian dengan nol dengan pesan yang jelas.
  6. TantanganBaca panjang tiga sisi, lalu tentukan apakah ketiganya membentuk segitiga (setiap dua sisi harus lebih panjang dari sisi ketiga). Bila ya, sebutkan jenisnya: sama sisi, sama kaki, atau sembarang.
  7. TantanganTulis ulang case pertama Program 6.5 sebagai rantai else if. Uji kedua versi dengan nilai-nilai batas yang sama, lalu jelaskan mana yang menurut Anda lebih mudah dibaca dan mengapa.
