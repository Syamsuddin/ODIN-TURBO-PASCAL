Hari dalam seminggu, bulan, jenis huruf, nilai ujian: semua ini sebenarnya dapat ditulis sebagai bilangan bulat, tetapi program menjadi sulit dibaca dan mudah salah. Pascal menyediakan tiga alat untuk membuat tipe data yang sesuai dengan masalahnya: enumerasi (daftar nama buatan sendiri), subrange (potongan rentang), dan set (himpunan). Ketiganya berbagi satu kesamaan: semuanya berdasar pada tipe ordinal.

Tipe Ordinal: Nilai yang Berurutan

Tipe ordinal adalah tipe yang nilainya dapat diurutkan dan dihitung satu per satu, seperti anak tangga: setiap nilai (kecuali yang pertama) punya nilai sebelumnya, dan setiap nilai (kecuali yang terakhir) punya nilai sesudahnya. Integer, Char, Boolean, enumerasi, dan subrange semuanya ordinal. Real bukan ordinal, sebab di antara dua bilangan real selalu ada bilangan real lain.

Tipe Enumerasi

Dengan enumerasi, Anda mendaftar sendiri semua nilai yang mungkin, lengkap dengan nama. Daripada menulis “hari ke-3” sebagai angka 3, Anda menulis Rabu. Program menjadi dokumentasi dirinya sendiri, dan kompiler menolak nilai di luar daftar.

type
  NamaTipe = (Nilai1, Nilai2, Nilai3);

var
  V: NamaTipe;

V := Nilai2;

Kompiler memberi nomor urut 0, 1, 2, ... sesuai urutan penulisan. Nama-nama itu adalah konstanta yang tidak berubah, bukan string, sehingga ditulis tanpa tanda kutip.

Aturan Turbo Pascal 7. Write dan WriteLn tidak dapat mencetak nilai enumerasi. WriteLn(Hari) ditolak kompiler. Dua cara umum: cetak nomor urut dengan Ord(Hari), atau simpan nama dalam array berindeks enumerasi lalu cetak NamaHari[Hari]. Cara kedua dipakai di program berikut. Demikian pula ReadLn tidak dapat membaca enumerasi.

Tipe Subrange

Nilai ujian tidak mungkin negatif atau lebih dari 100, dan nomor bulan hanya 1 sampai 12. Subrange menyatakan batas itu di dalam tipenya: sebuah potongan rentang dari tipe ordinal lain yang disebut tipe dasar (host type). Variabelnya diperlakukan seperti tipe dasarnya, hanya saja hanya boleh berisi nilai di dalam rentang.

type
  NamaTipe = Batas bawah .. Batas atas;
  TNilai = 0..100;
  TAwal  = 'A'..'Z';
  THariKerja = Senin..Jumat;      { dari enumerasi }

Subrange punya dua manfaat. Pertama, dokumentasi: pembaca langsung tahu bahwa TBulan berarti 1 sampai 12. Kedua, pengaman: dengan pemeriksaan jangkauan (range checking) aktif, memberi nilai di luar rentang menghentikan program dengan runtime error 201, daripada diam-diam menyimpan data yang salah. Subrange juga dapat menjadi indeks array, seperti array[TBulan] of Integer.

Periksa dulu, baru simpan. Pemeriksaan jangkauan adalah jaring pengaman, bukan cara menerima masukan pengguna. Masukan dari papan ketik harus diperiksa dengan if sebelum disimpan ke variabel subrange, agar pengguna mendapat pesan yang ramah, bukan program yang berhenti mendadak.

Tipe Set (Himpunan)

Himpunan adalah kumpulan nilai tanpa urutan dan tanpa kembar. Pikirkan daftar hari latihan seorang atlet: yang penting adalah hari mana saja yang termasuk, bukan urutan menuliskannya. Pascal mengungkapkan ini dengan set of disertai tipe dasar ordinal yang kecil.

type
  THimpunan = set of TipeDasar;

var
  H: THimpunan;

H := [nilai1, nilai2];      { himpunan berisi dua anggota }
H := [];                     { himpunan kosong }
H := [awal..akhir];       { rentang anggota }

Tipe dasar set harus ordinal dan berjumlah paling banyak 256 nilai (nomor urut 0 sampai 255). Karena itu set of THari, set of Char, dan set of 0..100 sah, tetapi set of Integer tidak. Di memori, himpunan disimpan sebagai deretan bit, satu bit per kemungkinan anggota.

Selain operator, ada dua prosedur untuk mengubah satu anggota: Include(H, x) menambahkan x ke H, dan Exclude(H, x) membuangnya. Keduanya aman dipanggil berulang: menambah anggota yang sudah ada, atau membuang yang tidak ada, tidak menimbulkan galat.

Himpunan tidak dapat dicetak dengan Write, dan anggotanya tidak dapat diambil dengan indeks. Untuk menampilkannya, jalankan perulangan atas semua nilai tipe dasar dan periksa dengan in, persis seperti prosedur Tampilkan pada program berikut.

Set of Char: memeriksa jenis karakter

Himpunan paling sering dipakai pada Char. Tanpa set, memeriksa huruf besar berarti menulis (C >= 'A') and (C <= 'Z'). Dengan set, cukup C in ['A'..'Z']. Set dapat disimpan sebagai konstanta bernama sehingga kondisi terbaca seperti kalimat: Sandi[I] in HurufBesar.

const HurufBesar = ['A'..'Z']; Angka = ['0'..'9']; Simbol = ['!', '@', '#', '$']; if Sandi[I] in HurufBesar then ...

Kesalahan yang Sering Terjadi

Mencetak nilai enumerasi

Kesalahan paling sering pada bab ini adalah mencetak enumerasi langsung.

program Hari; type THari = (Senin, Selasa, Rabu); var H: THari; begin H := Selasa; WriteLn('Hari ini: ', H); end.

Perbaikannya sudah Anda lihat di Program 14.1: tampilkan Ord(H) atau gunakan array nama NamaHari[H].

Nilai di luar rentang

program Luar; type TNilai = 0..100; var N: TNilai; begin N := 150; WriteLn(N); end.

Bila nilai berasal dari masukan, kompiler tidak dapat mengetahuinya, sehingga yang terjadi adalah galat saat program berjalan:

program Luar2; {$R+} type TNilai = 0..100; var N: TNilai; M: Integer; begin ReadLn(M); N := M; WriteLn(N); end.

Cegah dengan memeriksa (M >= Low(TNilai)) and (M <= High(TNilai)) sebelum menyalin.

Set dengan tipe dasar terlalu besar

program Besar; var S: set of Integer; begin S := [1, 2, 3]; end.

Pakai tipe dasar yang kecil, misalnya set of Byte atau subrange set of 1..100.

Memakai ReadLn untuk enumerasi

Sama seperti Write, ReadLn tidak dapat membaca enumerasi. Bacalah nomor atau teks, lalu terjemahkan sendiri dengan case atau perulangan yang mencocokkan nama pada array.

Rangkuman

  • Tipe ordinal (Integer, Char, Boolean, enumerasi, subrange) berurutan dan mendukung Ord, Succ, Pred, Low, High.
  • Enumerasi (A, B, C) membuat daftar nama buatan sendiri bernomor 0, 1, 2, ...; dapat dipakai pada for, case, dan perbandingan.
  • Turbo Pascal tidak dapat Write atau ReadLn enumerasi; gunakan Ord atau array nama berindeks enumerasi.
  • Subrange Awal..Akhir membatasi nilai suatu tipe ordinal; periksa masukan dengan if sebelum menyimpannya, sebab nilai di luar rentang menimbulkan runtime error 201.
  • Set set of T menyimpan himpunan nilai tanpa urutan dan tanpa kembar, paling banyak 256 anggota.
  • Operator set: + gabungan, * irisan, - selisih, in keanggotaan, = sama, <= himpunan bagian.
  • Include dan Exclude menambah dan membuang satu anggota; set tidak dapat dicetak langsung.
  • set of Char menyederhanakan pemeriksaan jenis karakter: C in ['0'..'9'].
