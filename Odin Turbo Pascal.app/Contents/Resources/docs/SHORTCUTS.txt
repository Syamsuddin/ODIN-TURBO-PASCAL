F1                  Help; di editor: bantuan untuk kata di kursor/seleksi
F2                  Save
F3                  Open
F5                  Zoom editor
F6                  Next editor
F4                  Go to cursor (debugger)
F7                  Trace into (debugger)
F8                  Step over (debugger)
F9                  Make
F10                 File menu
Ctrl+F9             Compile and run; continue in the debugger
Alt+F9              Compile
Ctrl+F2             Stop program/debugger
Alt+F3              Close editor
Alt+F5              User screen
Ctrl+F8             Toggle breakpoint
Ctrl+F7             Evaluate/Modify (debugger)
Alt+F8              Next diagnostic
Alt+X               Exit
Alt+Backspace       Undo

Ctrl+N / O / S      New / Open / Save
Ctrl+F              Find
Ctrl+H              Replace
Ctrl+G              Search again
Ctrl+J              Go to line
Ctrl+L              Delete current line
Ctrl+Y              Redo
Tab / Shift+Tab     Indent / Unindent current line
Insert              Toggle insert / overwrite

MAC ALTERNATIVES
Command+N / O / S   New / Open / Save
Command+B           Compile
Command+R           Compile and run
Command+F           Find
Command+W           Close editor
Command+Q           Quit
Command+C / V / X   Copy / Paste / Cut in the editor (Tk native bindings)
Command+Z           Undo in the editor (Tk native binding)

Menu mnemonics: Alt+F/E/S/R/C/D/O/W/H.
Di sebagian pengaturan Mac, tombol Option menghasilkan simbol khusus.
Gunakan klik menu atau pintasan Command bila mnemonic tidak diteruskan Tk.
Tekan Fn bersama F1..F12 jika tombol fungsi dipakai untuk kontrol perangkat.

USER SCREEN
Enter              Input newline
Arrow/Home/End      Terminal navigation
F1..F12, Insert    Diteruskan ke program (ReadKey, Turbo Vision)
Option+huruf       Alt+huruf untuk program (Esc + huruf), misalnya Alt+X
Mouse              Diteruskan ke program Turbo Vision yang memintanya
Ctrl+C             Interrupt process group
Ctrl+F2            Stop
Alt+F5             Hide User screen
F7/F8              Langkah debugger saat program berhenti, selain itu ke program
Ctrl+C             Saat debugging: hentikan sementara di statement berikutnya
Copy screen        Menyalin layar teks 80x25 ke clipboard

Ctrl+Insert/Shift+Insert dan Shift+Delete mengikuti binding clipboard Tk pada
platform terkait. Menu Edit tersedia apabila keyboard Mac tidak memiliki Insert.
