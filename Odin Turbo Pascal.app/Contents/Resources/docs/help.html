Bantuan Odin Turbo Pascal

IDE Pascal bergaya Turbo Pascal untuk belajar dan menulis program: editor, kompilator, terminal 80×25, dan debugger dalam satu jendela.

Versi 2.3.0GNU GPL v3 atau lebih barumacOS · Windows · Linux

1Selamat Datang #

1.1Tentang Odin #

Odin Turbo Pascal adalah IDE Pascal dengan tampilan terinspirasi IDE Turbo Pascal era DOS. Program ditulis di editor, dikompilasi menjadi program asli (native) untuk CPU Anda, lalu dijalankan di User screen, terminal 80 kolom × 25 baris yang bersifat interaktif.

Catatan

Odin bukan Borland Turbo Pascal dan tidak berafiliasi dengan Borland. Tidak ada berkas, logo, huruf, atau berkas bantuan Borland di dalamnya. Lihat Kompatibilitas.

1.2Fitur utama #

  • Editor dengan warna sintaks Turbo Biru Lembut, banyak jendela, cari-ganti, dan pemulihan otomatis.
  • Compiler odinpc bawaan (target macOS Intel dan Apple Silicon, Linux x86_64 dan arm64, Windows x86_64), dengan assembler, linker, debugger, dan runtime library sendiri.
  • User screen berbasis pseudo-terminal: ReadLn, unit Crt, dan aplikasi Turbo Vision berjalan interaktif, lengkap dengan mouse.
  • Debugger terpadu: breakpoint, langkah demi langkah, Watches, Local variables, Call stack, Evaluate/Modify.
  • Tutorial 20 bab dengan 89 program contoh dan buku PDF pendampingnya.
  • Referensi bahasa Pascal dan unit pustaka yang bisa dibuka dengan F1 pada kata di editor.

2Memulai #

2.1Program pertama #

  1. Pilih File > New.
  2. Ketik program berikut.
  3. Simpan ke folder kerja Anda dengan F2.
  4. Tekan Ctrl+F9 untuk mengompilasi dan menjalankan.
program Halo;
var
  Nama: string;
begin
  Write('Nama Anda: ');
  ReadLn(Nama);
  WriteLn('Halo, ', Nama);
end.

Ctrl+F9 selalu mengompilasi ulang sumber terbaru dan menjalankan executable bila build berhasil. Program yang gagal dikompilasi tidak akan menjalankan executable lama. Tombol Editor pada User screen kembali ke editor; Alt+F5 membukanya lagi.

Tip

Program menunggu masukan di User screen. Bila ReadLn terlihat diam, klik User screen, ketik masukan, lalu tekan Enter.

3Tutorial dan Buku #

3.1Tutorial Pascal untuk pemula #

File > Examples berisi tutorial 20 bab, dari bab01_01_halo_dunia.pas sampai proyek akhir bab20_03_buku_telepon.pas. Nama berkas mengikuti pola babNN_MM_topik.pas, jadi urut dengan sendirinya. Komentar dan keluaran program berbahasa Indonesia.

  • Bab 1–5: fondasi (program, tipe data, masukan/keluaran, operator).
  • Bab 6–8: alur kendali (percabangan, pengulangan, latihan logika).
  • Bab 9–10: prosedur, fungsi, dan rekursi.
  • Bab 11–14: struktur data (array, string, record, enumerasi, subrentang, set).
  • Bab 15–16: pencarian dan pengurutan.
  • Bab 17–20: berkas, pointer, unit, dan proyek akhir.
Perhatian

Program Bab 17 dan Bab 20 membuat berkas data (misalnya catatan.txt atau kontak.dat) di folder berkas .pas-nya. Contoh bawaan berstatus templat, jadi simpan salinannya ke folder sendiri dengan File > Save as supaya berkas data mudah dicari.

4Editor #

4.1Membuka dan menyimpan #

File > Open (F3) menerima .pas, .pp, .inc, dan berkas teks lain. Berkas yang sama dibuka satu kali saja.

  • Save (F2) menulis secara atomik ke folder tujuan, sehingga berkas tidak rusak bila penulisan terputus.
  • Bila berkas diubah pihak lain setelah dibuka, Odin mendeteksinya (lewat hash SHA-256) dan menanyakan tindakan Anda.
  • Save as membuat salinan. Contoh bawaan selalu diarahkan ke Save as.
  • Open mengenali UTF-8, UTF-8 dengan BOM, lalu CP437 untuk kode DOS lama. Gaya akhir baris LF atau CRLF dipertahankan, jadi berkas kembali identik byte demi byte saat disimpan. Berkas DOS dengan code page selain CP437 perlu dikonversi ke UTF-8 lebih dulu.
  • Recent files, Examples, dan Change directory mempercepat berpindah folder kerja.

4.2Menyunting #

Enter melanjutkan indentasi baris sebelumnya. Tab memasukkan spasi sesuai pengaturan, Shift+Tab menggeser baris ke kiri. Ctrl+L menghapus baris, Insert menukar mode sisip/timpa. Daftar lengkap ada di Pintasan Keyboard.

Options > Editor mengatur ukuran huruf (10–30), lebar tab (1–8), dan Syntax colors.

4.3Warna sintaks #

Skema Turbo Biru Lembut aktif secara bawaan, di latar biru tua. Matikan Syntax colors untuk kembali ke teks kuning klasik di latar biru.

putih tebalkata tercadang (begin, if, var)

Swatch di atas hanya perkiraan warna; warna tepat ditentukan oleh IDE.

4.4Mengatur jendela #

  • Window > List menampilkan editor yang terbuka; F6 berpindah ke jendela berikutnya.
  • Tile membagi layar, Cascade menumpuk jendela, F5 (Zoom) memperbesar atau mengembalikan jendela aktif.
  • Alt+F3 menutup jendela aktif.
  • Jendela Watches, Local variables, dan Call stack juga jendela desktop biasa, jadi ikut diatur Tile, Cascade, dan List.

4.5Mencari dan mengganti #

  • Find (Ctrl+F) mencari teks literal, bukan ekspresi reguler. Opsi case sensitive membedakan huruf besar dan kecil.
  • Replace (Ctrl+H) mengganti teks; Search again (Ctrl+G) melanjutkan pencarian.
  • Go to line (Ctrl+J) memindahkan kursor ke nomor baris.
  • Next error (Alt+F8) dan Find error menuju diagnostik atau baris runtime error.

4.6Bantuan untuk kata di kursor #

Letakkan kursor pada sebuah kata, misalnya ReadKey, lalu tekan F1. Odin membuka topik kata itu di referensi dan menandainya.

4.7Pemulihan sesi #

Setiap 10 detik Odin mencatat salinan isi editor ke recovery.json di folder pengaturan. Sumber pribadi Anda tidak ditimpa oleh mekanisme ini. Bila aplikasi berhenti tidak normal, pembukaan berikutnya menawarkan pemulihan; perubahan pada interval terakhir sebelum snapshot mungkin belum tercatat. Berkas pemulihan dihapus saat Anda keluar secara normal. Breakpoint ikut tersimpan.

5Kompilasi dan Run #

5.1Compile, Make, Build #

PerintahTombolPerilaku
CompileAlt+F9Memanggil compiler; unit yang belum berubah memakai hasil sebelumnya.
MakeF9Seperti Compile untuk program dan unit yang berubah.
Build—Semua unit dikompilasi ulang.
RunCtrl+F9Kompilasi lalu jalankan. Executable lama tidak pernah dijalankan bila build gagal.

Mengompilasi unit saja menghasilkan .ppu/.o tanpa executable dan tidak menjalankan apa pun.

Hasil build disimpan di build cache yang dipisahkan menurut path program dan pilihan compiler (lihat Lokasi berkas). Folder sumber Anda tidak pernah menerima berkas hasil build, dan compiler tidak diarahkan untuk menimpa executable di folder sumber.

5.2Primary file #

Tanpa Primary file, editor aktif menjadi target kompilasi. Untuk proyek yang terdiri atas beberapa unit, tetapkan program utamanya di Compile > Primary file, lalu Run akan selalu membangun berkas itu. Clear primary file mengembalikan perilaku awal.

5.3Pesan error #

  • Klik dua kali sebuah pesan untuk menuju sumber, baris, dan kolomnya.
  • Alt+F8 berpindah ke diagnostik berikutnya, termasuk warning dan hint.
  • Compile > Compiler messages menampilkan perintah dan seluruh keluaran compiler.
  • Runtime error: baris penyebabnya ditandai merah, baik saat Run biasa maupun saat debugging. Search > Find error kembali ke baris itu. Daftar kodenya ada di Kode runtime error.

5.4Options > Compiler #

  • Compiler Odin mengikuti bahasa Turbo Pascal 7; tidak ada pilihan mode lain.
  • Range checks dan overflow checks aktif secara bawaan.
  • Informasi baris untuk runtime error selalu dibuat. Debug > Start debugging membangun ulang dengan pengait debugger.

5.5Options > Directories #

Isi satu path unit atau include per baris. Unit di folder program ditemukan otomatis, begitu pula unit standar dan Odin Vision.

5.6Parameter program #

Run > Parameters menerima argumen dengan aturan kutip seperti shell, misalnya:

"hello world" 123

Program membacanya dengan ParamCount dan ParamStr(1), ParamStr(2), dan seterusnya. Argumen diteruskan sebagai daftar tanpa menjalankan shell, sehingga tanda seperti * atau ; tidak ditafsirkan.

5.7Mengekspor executable #

Compile > Export executable menyalin hasil build terakhir ke lokasi pilihan Anda. Executable hanya cocok dengan OS dan CPU mesin pembuatnya. Bila dibagikan, program hasil Odin memuat runtime library Odin yang berlisensi GPL v3 atau lebih baru, sehingga ketentuan GPL berlaku untuk executable itu.

6User Screen dan Terminal #

6.1Terminal 80×25 #

Program berjalan di pseudo-terminal sistem (ConPTY di Windows), sehingga masukan bersifat interaktif seperti di konsol sungguhan. Ukuran layar emulasi tetap 80 kolom × 25 baris; membesarkan jendela tidak mengubahnya. Karakter garis dan pola desktop Turbo Vision tampil benar.

Jendela terminal yang ditutup hanya disembunyikan, dan program yang sedang berjalan tidak dihentikan. Buka lagi dengan Alt+F5.

6.2Keyboard dan mouse #

  • Tombol F1–F12, Insert, panah, dan Home/End diteruskan ke program (ReadKey, Turbo Vision).
  • Mouse (klik, seret, roda) diteruskan ke program Turbo Vision yang memintanya.
  • Alt+huruf dikirim sebagai Esc + huruf. Di macOS, Option berperan sebagai Alt.
  • Ctrl+C mengirim interupsi ke seluruh grup proses. Ctrl+F2 menghentikan program.
  • Copy screen menyalin layar teks 80×25 ke clipboard.
  • Setelah program Turbo Vision selesai, isi layar sebelumnya kembali.

6.3Keterbatasan #

Ini bukan emulator terminal lengkap: tidak ada scrollback, true color, atau lebar glyph Unicode CJK yang akurat. Gunakan teks ASCII untuk program dengan tata letak kolom ketat.

7Debugger #

Program dikompilasi ulang dengan pengait debugger lalu dijalankan di User screen. LLDB, GDB, dan Xcode tidak diperlukan.

7.1Breakpoint #

  • Pasang atau lepas dengan Ctrl+F8 atau klik gutter kiri; ditandai lingkaran merah.
  • Penanda ikut bergeser saat baris disisipkan atau dihapus, dan tersimpan bersama pemulihan sesi.
  • Breakpoint di baris tanpa kode dipindahkan ke baris berikutnya yang berisi kode.
  • Breakpoint yang diubah selama sesi debug langsung berlaku. Clear breakpoints menghapus semuanya.

7.2Menjalankan dan melangkah #

PerintahTombolFungsi

Saat program berhenti, baris yang akan dijalankan ditandai hijau. Bila sumber diubah di tengah sesi, perintah langkah berikutnya menanyakan apakah program perlu dibangun ulang.

7.3Watches, Locals, Call stack #

  • Watches: Insert menambah, Delete menghapus, Enter mengubah ekspresi. Nilai diperbarui setiap program berhenti.
  • Local variables: variabel lokal pada frame terpilih.
  • Call stack: klik dua kali untuk memilih frame; Watches dan Local variables lalu memakai frame itu.

7.4Evaluate/Modify #

Ctrl+F7 menghitung ekspresi Pascal: variabel, field, indeks (dengan cek batas), ^, @, aritmetika, perbandingan, typecast, serta Ord, Chr, Length, High, Low, SizeOf. Fungsi buatan program tidak dipanggil. Modify menulis nilai baru ke variabel dengan pemeriksaan jangkauan.

Format nilai mengikuti Turbo Pascal: 'abc', (1, 2, 3), (X:1; Y:2), [1, 3..5], TRUE, PTR($...), dan nama enumerasi.

7.5Contoh sesi #

  1. Buka bab10_01_faktorial_rekursif.pas dari File > Examples.
  2. Pasang breakpoint di baris pemanggilan fungsi dengan Ctrl+F8.
  3. Pilih Debug > Start debugging; program berhenti di breakpoint.
  4. Buka Call stack lalu tekan F7 beberapa kali dan amati tumpukan rekursi bertambah.
  5. Tambahkan N ke Watches untuk melihat nilainya berubah di tiap frame.

9Referensi Bahasa Pascal #

Ringkasan bahasa yang berlaku di Odin. Ketik kata di kotak pencarian atas (/) untuk melompat langsung ke rutin atau kata cadangannya. Ukuran tipe mengikuti mode Turbo Pascal.

9.1Struktur program dan contoh #

program NamaProgram;
uses Crt;
const Maksimum = 10;
var I: Integer;
begin
  for I := 1 to Maksimum do
    WriteLn(I);
end.

Percabangan

if Nilai >= 75 then
  WriteLn('Lulus')
else
  WriteLn('Belum lulus');

Tidak ada titik koma sebelum else yang berpasangan dengan if tersebut. Gunakan begin/end bila cabang berisi lebih dari satu pernyataan.

Pengulangan

for I := 1 to 10 do WriteLn(I);

while I < 10 do
begin
  Inc(I);
end;

repeat
  ReadLn(I);
until I = 0;

Procedure dan function

procedure Sapa(Nama: string);
begin
  WriteLn('Halo ', Nama);
end;

function Kuadrat(X: Integer): LongInt;
begin
  Kuadrat := LongInt(X) * X;
end;

Record

type
  TSiswa = record
    Nama: string[50];
    Nilai: Integer;
  end;

Unit buatan sendiri

unit UContoh;
interface
procedure Halo;
implementation
procedure Halo;
begin
  WriteLn('Halo');
end;
end.

Unit dipakai dari program melalui uses UContoh. Simpan sumber dengan nama sesuai nama unit, dan pastikan direktorinya ditemukan compiler (lihat Directories).

Tip

Gaya Turbo Pascal 7: tidak ada Result (isi nama fungsi), enumerasi tidak bisa di-Write, dan setiap Real sebaiknya diformat: Write(X:0:2).

9.2Kata cadangan #

Kata cadangan tidak boleh dipakai sebagai nama variabel, konstanta, tipe, atau rutin. Huruf besar-kecil tidak dibedakan.

NamaKeterangan
andOperator logika AND untuk Boolean, dan AND bit demi bit untuk bilangan bulat. Prioritasnya lebih tinggi daripada perbandingan, jadi beri tanda kurung: (A > 0) and (B > 0).
arrayTipe larik: array[1..10] of Integer, array[Boolean] of Byte, array[1..3, 1..3] of Real (dua dimensi). Indeks bisa tipe ordinal apa pun.
asmMembuka blok bahasa rakitan, ditutup end. Belum didukung compiler Odin.
beginMembuka blok pernyataan majemuk, ditutup end. Badan program, prosedur, dan fungsi selalu diawali begin.
casePercabangan banyak arah pada nilai ordinal: case N of 1: ...; 2, 3: ...; 4..9: ...; else ... end. Selector tidak boleh String atau Real. Juga dipakai di bagian varian record.
constBagian deklarasi konstanta (const Maks = 10;) atau konstanta bertipe yang bisa diubah (const Hitung: Integer = 0;).
constructorMetode khusus object yang menyiapkan instance dan tabel metode virtualnya. Biasanya bernama Init: constructor TKotak.Init(...).
destructorMetode khusus object yang membersihkan instance, biasanya bernama Done: destructor TKotak.Done; virtual;
divPembagian bulat tanpa pecahan: 17 div 5 = 3. Pembagian dengan nol menimbulkan runtime error 200.
doBagian dari for ... do, while ... do, dan with ... do; memisahkan kepala dari pernyataan yang diulang.
downtoPada for, menghitung mundur: for I := 10 downto 1 do ...
elseCabang lain pada if atau case. Jangan beri titik koma tepat sebelum else yang berpasangan dengan if.
endMenutup begin, case, record, object, asm, atau unit/program (end. dengan titik).
exportsDaftar rutin yang diekspor dari library. Tidak berguna pada program biasa.
fileTipe berkas. file of Integer = berkas bertipe, file saja = berkas tanpa tipe untuk BlockRead/BlockWrite.
forPengulangan dengan jumlah tetap: for I := 1 to N do ... Variabel kontrol harus ordinal lokal; nilainya tidak boleh diubah di dalam badan dan tidak terdefinisi setelah selesai.
functionMendeklarasikan fungsi yang mengembalikan nilai. Nilai diberikan dengan menugaskan ke nama fungsi (Kuadrat := X * X). Variabel Result tidak ada di Turbo Pascal.
gotoMelompat ke label yang dideklarasikan dengan label. Hindari, tetapi sah dalam satu blok.
ifPercabangan: if Kondisi then A else B. Kondisi bertipe Boolean.
implementationBagian unit berisi badan rutin dan deklarasi privat; di bawah interface.
inOperator keanggotaan himpunan: if Huruf in ['a'..'z'] then ...
inheritedMemanggil metode induk dari dalam metode turunan: inherited Init(...).
inlineMenyisipkan byte kode mesin langsung. Tidak dapat dikompilasi di macOS 64-bit (lihat COMPATIBILITY.txt).
interfaceBagian unit yang terlihat oleh pemakai unit: konstanta, tipe, variabel, dan kepala rutin.
labelMendeklarasikan label tujuan goto: label Selesai;
libraryMenandai sumber sebagai pustaka dinamis, bukan program.
modSisa pembagian bulat: 17 mod 5 = 2. Hasil mengikuti tanda pembilang.
nilPointer kosong yang tidak menunjuk apa pun. Cocok dengan tipe pointer apa pun.
notNegasi Boolean, atau pembalikan bit pada bilangan bulat: not True = False.
objectTipe objek gaya Turbo Pascal 7 dengan field dan metode: TKotak = object(TInduk) ... end;
ofDipakai pada array ... of, case ... of, file of, set of, dan deklarasi object.
orOperator logika OR (Boolean) atau OR bit demi bit. Beri tanda kurung pada perbandingan.
packedMeminta penyimpanan padat untuk array, record, atau set. Di Turbo Pascal 7 tidak berefek pada record biasa; pakai packed record untuk data dialog Odin Vision.
procedureMendeklarasikan prosedur (subprogram tanpa nilai kembali). Parameter var dilewatkan per acuan.
programKepala program: program Nama; atau program Nama(Input, Output);
recordTipe rekaman dengan field bernama; boleh punya bagian varian: record ... case Tipe: Byte of ... end;
repeatPengulangan yang menguji kondisi di akhir: repeat ... until Kondisi; badan selalu jalan minimal sekali.
setTipe himpunan: set of Char, set of 0..255. Maksimum 256 elemen.
shlGeser bit ke kiri: 1 shl 3 = 8.
shrGeser bit ke kanan: 16 shr 2 = 4.
stringTipe teks. string = hingga 255 karakter; string[N] = panjang maksimum N; indeks 0 menyimpan panjang.
thenMengikuti kondisi pada if.
toPada for, menghitung naik: for I := 1 to 10 do ...
typeBagian deklarasi tipe baru: type TSiswa = record ... end;
unitKepala unit: unit Nama; lalu interface, implementation, dan opsional initialization.
untilPenutup repeat; pengulangan berhenti ketika kondisinya True.
usesMengimpor unit: uses Crt, Dos;. Unit System selalu otomatis.
varDeklarasi variabel, atau parameter per acuan pada prosedur/fungsi: procedure Tukar(var A, B: Integer);
whilePengulangan yang menguji kondisi di awal: while Kondisi do ... Badan bisa tidak jalan sama sekali.
withMempersingkat akses field: with Siswa do Nama := 'Budi'; (setara Siswa.Nama := 'Budi';).
xorOperator OR eksklusif: Boolean atau bit demi bit.
class, try, exceptKata tambahan Object Pascal (dialek yang lebih baru). finally, raise, out, property, dan threadvar juga dicadangkan. Tidak ada di Turbo Pascal 7; jangan dipakai sebagai nama.

12.2Yang sudah dan belum diuji #

Batas klaim

Yang diuji: compiler Odin di Mac Intel (Darwin 24.6), VM Ubuntu 24.04 (x86_64, dan aarch64 lewat qemu), serta runner GitHub Actions untuk macOS 15 Apple Silicon, Ubuntu x86_64 dan arm64, dan Windows Server 2025. Belum diuji langsung: Mac Apple Silicon fisik, PC Linux fisik, PC Windows fisik, installer di Apple Silicon dan Windows, Mac bersih tanpa Xcode Command Line Tools, LaunchServices/Gatekeeper, serta Option pada keyboard Mac sungguhan.

12.3Compiler #

Compiler adalah toolchain Odin: odinpc (Rust) dengan assembler, linker, debugger, dan runtime library sendiri. Target: x86_64-darwin, aarch64-darwin (Mach-O, dengan tanda tangan kode ad-hoc yang diwajibkan macOS di Apple Silicon), x86_64-linux dan aarch64-linux (ELF dinamis, glibc 2.34 atau lebih baru), x86_64-windows (PE32+). Sampai 2.3.0 Free Pascal bisa dipilih sebagai backend alternatif; backend itu, beserta mode ObjFPC/Delphi, sudah dicabut.

  • Bahasanya Turbo Pascal 7 di platform 64-bit. Perbedaan CPU, ukuran pointer, ABI, sistem berkas, dan unit tetap berlaku.
  • Di arm64, bendera FPSR diperiksa sesudah operasi real sehingga runtime error 207, 200, atau 205 muncul seperti di x86-64.
  • Di Windows, berkas teks memakai CRLF, path memakai \ dan huruf drive, dan Printer mencetak lewat notepad /p.

12.5Fitur era DOS #

Tidak dapat dikompilasi di sistem 64-bit: Mem/MemW/MemL, Port, absolute $Seg:$Ofs, PrefixSeg, MemAvail/MaxAvail, Test8087, inline(...), prosedur interrupt, serta Intr/MsDos/Registers. GetIntVec/SetIntVec dan Keep dapat dikompilasi tetapi tidak berefek. Blok asm belum didukung.

12.6Perbedaan perilaku penting #

HalTurbo Pascal 7Odin
Real6 byte8 byte. Real48 tidak tersedia; berkas biner Real dari TP perlu dikonversi lebih dahulu.
Pointer4 byte8 byte. Integer tetap 2 byte, LongInt 4 byte di mode TP.
Round(2.5)32 (pembulatan ke genap). Periksa program yang bergantung pada nilai .5.

Jangan menganggap tata letak record atau berkas biner DOS, atau aritmetika pointer, identik di macOS 64-bit.

13.2Tanya jawab #

Apakah saya harus memasang Free Pascal atau Xcode?

Tidak. Compiler odinpc sudah disertakan dan menjadi satu-satunya compiler; satu-satunya dependensi adalah Python dengan Tk.

Mengapa program saya tidak bisa membaca berkas biner dari Turbo Pascal 7?

Tipe Real berbeda ukuran (6 byte di TP, 8 byte di sini), dan Real48 tidak tersedia. Konversikan berkas itu lebih dahulu.

Dapatkah saya membagikan program yang saya kompilasi?

Ya, lewat Compile > Export executable. Executable hanya jalan di OS dan CPU yang sama, dan program hasil Odin memuat runtime GPL (lihat Mengekspor executable).
