Selama 22 bab Anda menulis program yang mengikuti aturan buatan Anda sendiri: bila nilai di atas 75, cetak "Lulus". Bagaimana bila aturannya tidak diketahui? Misalnya, berapa nilai ujian seorang siswa yang belajar 5 jam? Tidak ada rumus pasti, tetapi ada data: catatan jam belajar dan nilai puluhan siswa sebelumnya. Machine learning (pembelajaran mesin) adalah cara membuat komputer menemukan sendiri pola dari data seperti itu. Bab ini memakai sepuluh program pertama dari menu File ▸ Examples - AI..., yaitu contoh pustaka OTP-AI yang ditulis seluruhnya dalam Pascal.

Dari Aturan ke Data

Bayangkan dua cara mengajari anak mengenali kucing. Cara pertama, Anda menulis aturan: berkaki empat, berbulu, bertelinga runcing, berkumis. Aturan seperti ini cepat rusak, karena anjing juga berkaki empat dan berbulu. Cara kedua, Anda menunjukkan ratusan foto sambil berkata "ini kucing" atau "ini bukan kucing", sampai anak itu bisa menebak foto yang belum pernah ia lihat. Cara kedua inilah machine learning.

1Pemrograman biasa

Aturan + data → jawaban. Programmer menulis aturan if Nilai >= 75 then ..., komputer menerapkannya.

2Machine learning

Data + jawaban → aturan. Komputer diberi contoh berpasangan (jam belajar dan nilai), lalu mencari aturan yang paling cocok. Aturan itu disebut model.

Pola Need dan COMMON.INC

Hampir semua rutin OTP-AI adalah fungsi Boolean: hasilnya True bila berhasil dan False bila gagal, misalnya berkas CSV tidak ditemukan atau ukuran data melebihi batas. Pesan kesalahannya tersimpan di AIError dan kodenya di AIErrorCode. Contoh-contoh OTP-AI menyertakan berkas COMMON.INC dengan direktif {$I COMMON.INC}, yang menempelkan isi berkas itu ke dalam program. Isinya dua rutin pembantu.

procedure Need(OK: Boolean); begin if not OK then begin WriteLn('GAGAL [',AIErrorCode,']: ',AIError); Halt(1) end end; function DataPath(Name: TFileName): TFileName; { 'DATA/X.CSV', atau '../DATA/X.CSV' }

Jadi Need(LoadCSV(...)) berarti "muat CSV; bila gagal, cetak alasannya lalu hentikan program". Program tidak pernah melanjutkan perhitungan dengan data yang rusak. DataPath mencari folder DATA di folder kerja, lalu di folder induknya. Program dijalankan dengan folder sumbernya (otp-AI/EXAMPLES) sebagai folder kerja, jadi datanya ditemukan di ../DATA.

Contoh OTP-AI ditulis agar juga bisa dikompilasi Turbo Pascal asli dan Free Pascal. Karena itu setiap program diawali direktif seperti {$IFNDEF FPC} {$M 16384,0,655360} {$ENDIF} (ukuran stack dan heap di DOS) dan {$R+}{$S+}{$B-}. Data besar bertipe TDataSet (200 baris x 8 fitur) selalu disimpan di memori dinamis lewat pointer PDataSet, yang dibuat NewData dan dibebaskan FreeData, karena segmen data DOS hanya 64 KB. Itulah sebabnya Anda akan sering melihat D^.

Menyiapkan Data

Data nyata jarang rapi: ada nilai yang kosong, satuan yang berbeda jauh (jam 1..12, nilai 0..100), dan kategori berupa teks. Sebelum dilatih, data perlu praproses. Satu aturan penting: model harus diuji dengan data yang tidak pernah dilihatnya saat belajar, seperti ujian yang soalnya tidak dibocorkan. Karena itu data dibagi menjadi data latih dan data uji, dan semua langkah praproses yang "belajar" dari data (mencari rata-rata, simpangan baku) hanya boleh melihat data latih.

Regresi Linear

Regresi linear mencari garis lurus Y = a + b · X yang paling dekat dengan semua titik data. "Paling dekat" berarti jumlah kuadrat selisih antara nilai sebenarnya dan nilai pada garis sekecil mungkin; metode ini disebut ordinary least squares (OLS). Setelah garisnya ditemukan, menebak nilai untuk X baru cukup dengan memasukkannya ke rumus.

Klasifikasi dengan K-Nearest Neighbors

KNN adalah model klasifikasi yang paling mudah dibayangkan: "katakan siapa tetanggamu, akan kukatakan siapa dirimu". Untuk menebak kelas sebuah titik baru, cari K titik latih yang jaraknya paling dekat, lalu ambil kelas yang paling banyak di antara mereka. KNN tidak benar-benar "belajar"; ia hanya mengingat semua data latih.

Hasil klasifikasi dirangkum dalam confusion matrix: baris adalah kelas sebenarnya, kolom adalah kelas tebakan. Angka di diagonal adalah tebakan yang benar; angka di luar diagonal adalah "kebingungan" model. Accuracy adalah bagian tebakan yang benar, dan macro-F1 merata-ratakan keseimbangan ketepatan setiap kelas, sehingga kelas yang sedikit anggotanya tetap ikut dihitung.

BarisPenjelasan
22TargetClass: kolom terakhir BUNGA.CSV adalah kelas 0, 1, atau 2, disimpan di Labels, bukan di Y.
23–2530% data menjadi data uji, lalu kedua bagian distandarkan dengan scaler yang dilatih dari data latih.

Accuracy 1,0000 di sini wajar karena data bunganya sintetis dan kelasnya terpisah jelas. Pada data sungguhan, accuracy sempurna justru patut dicurigai: periksa apakah ada data leakage atau data uji yang terlalu sedikit.

K-Means: Mengelompokkan Tanpa Label

Semua contoh sejauh ini terawasi (supervised): setiap baris punya jawaban. Kadang data tidak punya label sama sekali, misalnya catatan belanja pelanggan, dan kita ingin menemukan kelompok-kelompok alaminya. Inilah klastering, salah satu bentuk pembelajaran tak terawasi (unsupervised). K-means bekerja dalam putaran berikut sampai pusat tidak lagi bergeser.

3Geser pusatpusat baru = rata-rata anggota kelompoknya

Validasi Silang

Satu kali pembagian latih/uji bisa beruntung atau sial, tergantung baris mana yang kebetulan masuk data uji. Validasi silang K-fold lebih adil: data dibagi menjadi 5 bagian (fold). Model dilatih 5 kali; setiap kali satu fold menjadi data uji dan empat sisanya data latih. Setiap baris tepat sekali menjadi data uji.

BarisPenjelasan

28FoldSplit menjadikan fold ke-Fold data uji (Te) dan sisanya data latih (Tr).

Regresi Logistik dan Gradient Descent

Regresi logistik dipakai untuk klasifikasi dua kelas. Model menghitung z = a + b₁X₁ + ..., lalu memasukkannya ke sigmoid sehingga hasilnya menjadi peluang 0..1. Bila peluangnya di atas ambang (biasanya 0,5), tebakannya kelas 1. Berbeda dengan OLS, koefisiennya tidak dihitung dengan rumus langsung, melainkan dicari sedikit demi sedikit dengan gradient descent: setiap putaran (epoch), koefisien digeser ke arah yang mengurangi loss (ukuran seberapa salah model), seperti menuruni bukit selangkah demi selangkah.

BarisPenjelasan

27DefaultTraining mengisi konfigurasi bawaan unit AIOptim: paling banyak 2000 epoch, learning rate 0,1, target loss 0,01, dan patience 300 (berhenti bila loss tidak membaik selama 300 epoch).
28LogisticData menghitung peluang setiap baris uji (P) dan mengubahnya menjadi label dengan ambang 0,5 (L).

Perceptron dan Jaringan Saraf

Perceptron adalah "neuron" buatan paling sederhana: ia menjumlahkan masukan berbobot, lalu menjawab 1 bila jumlahnya melewati ambang. Secara geometri, perceptron menarik satu garis lurus untuk memisahkan dua kelas. Itu cukup untuk AND, tetapi tidak untuk XOR, karena tidak ada satu garis pun yang bisa memisahkan titik-titik XOR.

BarisPenjelasan
23FitPerceptron(Data, MaksEpoch, Rate, Seed, Model, Info): paling banyak 100 epoch dengan learning rate 0,1.
24–28AND konvergen di epoch 8, dan keempat kombinasi masukan ditebak benar: hanya 1 1 yang menghasilkan 1.
29–31Dataset yang sama dipakai ulang untuk XOR. Setelah 100 epoch belum konvergen dan setengah tebakannya salah (error=0.5000), sama dengan menebak asal.

Jawabannya adalah menyusun beberapa neuron dalam lapisan. Jaringan saraf 2-4-1 di bawah punya 2 masukan, 4 neuron di lapisan tersembunyi, dan 1 keluaran. Setiap neuron tersembunyi menarik garisnya sendiri, dan neuron keluaran menggabungkan garis-garis itu menjadi batas yang berbelok.

Kesalahan yang Sering Terjadi

Lupa menulis unitnya di uses. Setiap rutin OTP-AI berasal dari unit tertentu; Mean ada di AIStats, bukan di AIMath.

program lupa_unit; uses AITypes, AIMath; var S: TSeries; Nilai: TFloat; begin S[1] := 4; S[2] := 8; if Mean(S, 2, Nilai) then WriteLn('Mean: ', Nilai:0:2); end.

Memakai Need tanpa COMMON.INC. Need bukan bagian unit OTP-AI, melainkan prosedur dari berkas include contoh. Di program sendiri, salin COMMON.INC ke folder program Anda, atau tulis prosedur Need sendiri.

program lupa_need; uses AITypes, AIMath; var V, W: TVector; Jarak: TFloat; begin FillChar(V, SizeOf(V), 0); FillChar(W, SizeOf(W), 0); W[1] := 3; W[2] := 4; Need(Euclidean(V, W, 2, Jarak)); WriteLn('Jarak: ', Jarak:0:2); end.

Lupa tanda ^ pada PDataSet. Rutin data menerima TDataSet, sedangkan D hanya pointer ke dataset itu.

program lupa_tanda; uses AITypes, AIData; var D: PDataSet; begin if NewData(D) then if LoadCSV('JAMNILAI.CSV', True, TargetReal, D) then WriteLn('Baris: ', D^.Count); end.

Mengabaikan hasil False. Bila berkas tidak ada, LoadCSV menjawab False dan AIError menjelaskan sebabnya. Program yang tidak memeriksanya akan melanjutkan dengan dataset kosong.

program tanpa_data; uses AITypes, AIData; var D: PDataSet; begin if not NewData(D) then Halt(1); if not LoadCSV('NILAI2025.CSV', True, TargetReal, D^) then begin WriteLn('GAGAL [', AIErrorCode, ']: ', AIError); Halt(1); end; WriteLn('Baris: ', D^.Count); FreeData(D); end.
  • Menilai model dengan data latih. Nilai pada data latih selalu terlalu optimis; pakai data uji atau validasi silang.
  • Melatih scaler atau imputer sebelum membagi data (data leakage).
  • Lupa menskalakan fitur untuk model berbasis jarak (KNN, K-means): fitur bersatuan besar menguasai jarak.
  • Membebaskan dataset yang masih ditunjuk model KNN. Lepaskan dulu Model.Data := nil.
  • Melebihi batas OTP-AI: paling banyak 200 baris, 8 fitur, dan 10 kelas. Rutin akan menjawab False dengan galat ukuran.

Rangkuman

  • Machine learning menemukan aturan (model) dari contoh data. Regresi menebak bilangan, klasifikasi menebak kelas, dan klastering mengelompokkan data tanpa label.
  • Unit OTP-AI terpasang bersama IDE. Rutinnya fungsi Boolean; Need dari COMMON.INC menghentikan program dengan pesan AIError bila ada yang gagal.
  • Dataset besar disimpan lewat PDataSet: NewData, D^, FreeData.
  • Bagi data menjadi latih dan uji lebih dulu; imputer, scaler, dan model hanya dilatih dari data latih.
  • Regresi diukur dengan MAE, RMSE, dan R²; klasifikasi dengan confusion matrix, accuracy, dan macro-F1.
  • KNN dan K-means memakai jarak, jadi fitur perlu distandarkan. Validasi silang K-fold memberi penilaian yang lebih adil daripada satu pembagian.
  • Regresi logistik, perceptron, dan jaringan saraf dilatih dengan gradient descent per epoch sampai loss mencapai target.
  • Perceptron tunggal hanya bisa memisahkan kelas dengan satu garis; jaringan saraf dengan lapisan tersembunyi bisa menyelesaikan XOR.
