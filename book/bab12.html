Hampir setiap program yang berguna berurusan dengan teks: nama, alamat, kalimat, kode pos, nomor telepon. Anda sudah memakai string sejak Bab 3 untuk menyimpan dan menampilkan teks. Sekarang saatnya membuka isinya. Di Pascal, string tidak lain adalah deretan karakter yang masing-masing punya nomor urut, sama seperti elemen array pada Bab 11. Dengan perulangan dan beberapa fungsi bawaan, Anda dapat memotong, mencari, menyisipkan, membalik, dan memeriksa teks.

String sebagai Deretan Karakter

Sebuah nilai bertipe string terdiri dari nol atau lebih karakter. Karakter pertama bernomor 1, karakter kedua bernomor 2, dan seterusnya. Untuk mengambil satu karakter, tulis nama string diikuti nomornya di dalam kurung siku, persis seperti elemen array: S[3] adalah karakter ketiga dari S, bertipe Char. Banyaknya karakter disebut panjang string, dan diperoleh dari fungsi Length(S). String yang panjangnya nol, ditulis '', disebut string kosong.

Karena karakter-karakternya berindeks, hampir semua pola yang Anda pelajari pada array berlaku juga untuk string: perulangan for I := 1 to Length(S) menelusuri teks dari awal sampai akhir, dan for I := Length(S) downto 1 menelusurinya dari belakang. Bedanya, string memiliki satu set fungsi bawaan khusus untuk pekerjaan yang sering dilakukan pada teks.

1Membaca

S[I] mengambil satu karakter. Length(S) memberi panjangnya.

2Memotong dan mencari

Copy mengambil potongan, Pos mencari letak sebuah teks dalam string.

3Mengubah

Insert menyisipkan, Delete menghapus, UpCase membesarkan huruf, dan + menyambung.

Di Turbo Pascal 7, string panjangnya paling banyak 255 karakter. Anda juga dapat membatasi panjang maksimum dengan string[20]. Nilai yang lebih panjang dari batasnya dipotong diam-diam. Karakter dalam string bertipe Char, dan untuk Char yang dipakai adalah petik tunggal: 'A'.

Membalik Huruf dan Membalik Kata

Membalik string adalah latihan klasik yang melatih Anda menelusuri string dan membangun string baru. Ada dua versi yang berbeda sifatnya. Membalik huruf menjadikan pascal menjadi lacsap. Membalik urutan kata menjadikan saya suka pascal menjadi pascal suka saya, dengan huruf di dalam kata tetap utuh.

Cara membalik huruf: mulai dari string hasil yang kosong, baca string asal dari karakter terakhir ke pertama, dan tempelkan tiap karakter ke belakang hasil. Karena yang dibaca paling akhir menjadi yang tertempel paling awal, hasilnya terbalik. Membalik urutan kata lebih rumit: program memotong satu kata dari depan string, lalu menaruhnya di depan hasil, dan mengulanginya sampai string asal habis.

Kedua pekerjaan ini ditulis sebagai fungsi yang mengembalikan string. Di Turbo Pascal, hasil fungsi diberikan dengan menugaskan nilai ke nama fungsinya sendiri (BalikHuruf := Hasil;), bukan dengan Result.

Pada keluaran, Huruf dibalik menampilkan lacsap akus ayas: dua spasi tetap ada, karena membalik huruf memperlakukan spasi seperti karakter lain. Pada Kata dibalik, spasi ganda dirapikan menjadi satu spasi. Gambar berikut menelusuri BalikUrutanKata untuk masukan yang sama, saya suka pascal (dengan dua spasi setelah saya).

Palindrom

Palindrom adalah kata atau kalimat yang terbaca sama dari depan maupun dari belakang, seperti kakak, katak, atau Kasur ini rusak. Untuk kalimat, spasi dan perbedaan huruf besar dan kecil diabaikan. Program harus mengerjakan dua hal: membersihkan teks (membuang selain huruf dan angka, lalu menjadikan semuanya kapital) dan memeriksa apakah teks bersih itu palindrom.

Memeriksa palindrom tidak perlu membuat string terbalik. Cukup dua penunjuk: Kiri mulai dari karakter pertama dan Kanan mulai dari karakter terakhir. Keduanya dibandingkan, lalu bergerak ke tengah satu langkah demi satu langkah. Begitu ada pasangan yang berbeda, teks bukan palindrom. Bila kedua penunjuk bertemu tanpa menemukan perbedaan, teks adalah palindrom.

Mengubah Angka dan String

Angka 1250 dan string '1250' terlihat sama di layar, tetapi bagi komputer keduanya berbeda jenis: yang satu bilangan yang bisa dijumlahkan, yang lain deretan empat karakter. Untuk berpindah dari satu bentuk ke bentuk lain, Pascal menyediakan dua prosedur:

Str(bilangan, S);                  { bilangan menjadi string }
Str(bilangan:lebar:desimal, S);    { dengan format, untuk Real }
Val(S, bilangan, Kode);             { string menjadi bilangan }

Str bekerja seperti WriteLn yang hasilnya disimpan ke variabel string, bukan ditampilkan. Val memiliki parameter ketiga yang unik, yaitu kode galat. Bila seluruh string berhasil dibaca sebagai bilangan, Kode bernilai 0. Bila tidak, Kode berisi nomor posisi karakter pertama yang salah, dan bilangannya tidak boleh dipercaya.

VVal: kode 0

Val('1250', Harga, Kode) menghasilkan Harga = 1250 dan Kode = 0. Aman dipakai.

XVal: kode bukan 0

Val('12a50', Harga, Kode) menghasilkan Kode = 3, karena a adalah karakter ke-3. Harga tidak boleh dipakai.

Mengapa tidak langsung memakai ReadLn(Harga)? Karena bila pengguna mengetik huruf, program akan berhenti dengan runtime error. Dengan membaca masukan sebagai string lalu memeriksanya dengan Val, program Anda dapat memberi pesan yang ramah dan meminta pengguna mengulang. Pola ini, baca sebagai teks, validasi, baru pakai, dipakai di hampir semua program yang menerima ketikan pengguna.

Kesalahan yang Sering Terjadi

Menugaskan string ke Char

Variabel Char hanya menampung satu karakter. Memberinya teks dua huruf atau lebih ditolak oleh kompiler.

program CharDua; var C: Char; begin C := 'AB'; WriteLn(C); end.

Bila yang Anda inginkan adalah teks, deklarasikan variabelnya sebagai string. Bila yang Anda inginkan adalah karakter pertama, tulis C := S[1];.

Menyimpan angka bukan di tempat yang tepat

Keliru memakai variabel string untuk menerima hasil Length, atau sebaliknya, adalah kesalahan tipe yang umum. Length selalu menghasilkan bilangan.

program Panjang; var Teks, Banyak: string; begin Teks := 'Pascal'; Banyak := Length(Teks); WriteLn('Panjang: ', Banyak); end.

Perbaikannya: deklarasikan Banyak sebagai Integer. Bila Anda memang membutuhkan bilangan itu sebagai teks, gunakan Str(Length(Teks), Banyak).

Val dengan kode galat yang salah tipe

Parameter ketiga Val harus bertipe bilangan bulat. Memberinya variabel bertipe lain ditolak.

program ValSalah; var Angka: Integer; Kode: Real; begin Val('123', Angka, Kode); WriteLn(Angka); end.

Indeks di luar panjang string

Seperti array, string yang diakses di luar rentangnya bermasalah. Akses karakter nomor 0 atau nomor yang lebih besar dari Length mengambil data yang bukan bagian dari teks. Pada perulangan selalu batasi indeks dengan Length(S), dan pada Copy, Insert, Delete pastikan posisi awal berada di dalam string. Ingat pula bahwa Pos bernilai 0 bila teks tidak ditemukan, sehingga hasilnya harus diperiksa sebelum dipakai sebagai posisi.

Rangkuman

  • String adalah deretan karakter yang berindeks mulai dari 1. S[I] adalah karakter ke-I bertipe Char, dan Length(S) adalah banyaknya karakter.
  • Copy(S, Awal, N) mengambil potongan, Pos(Cari, S) mencari posisi (0 bila tidak ada), Insert menyisipkan, dan Delete menghapus. Insert dan Delete mengubah variabelnya.
  • UpCase bekerja pada satu Char; untuk string utuh dibutuhkan perulangan. String disambung dengan + atau Concat.
  • Fungsi boleh mengembalikan string. Di Turbo Pascal hasilnya ditugaskan ke nama fungsi, bukan ke Result.
  • Membalik huruf: baca dari belakang ke depan dan tempelkan ke hasil. Membalik kata: potong kata di depan, taruh di depan hasil.
  • Palindrom diperiksa dengan membandingkan karakter dari kedua ujung bergerak ke tengah, setelah teks dibersihkan dari spasi dan dikapitalkan.
  • Menghitung jenis karakter memakai case dengan label daftar dan rentang; else menampung sisanya.
  • Str mengubah bilangan menjadi string (boleh berformat), Val mengubah string menjadi bilangan dengan kode galat 0 bila sukses atau posisi karakter yang salah. Baca masukan sebagai string, validasi dengan Val, baru pakai.
