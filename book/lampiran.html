Odin Turbo Pascal berjalan di macOS, Windows, dan Linux. Berikut langkah pemasangan lengkap untuk setiap sistem. Versi yang dibahas adalah Odin Turbo Pascal {{VERSI}}. Petunjuk terbaru selalu ada di berkas README yang menyertai aplikasi.

Paket dan kode sumber Odin Turbo Pascal ada di repositori GitHub github.com/Syamsuddin/ODIN-TURBO-PASCAL. Daftar rilis beserta catatan perubahannya ada di github.com/Syamsuddin/ODIN-TURBO-PASCAL/releases.

macOS

  1. Unduh dan ekstrak. Buka github.com/Syamsuddin/ODIN-TURBO-PASCAL, unduh paketnya (Code ▸ Download ZIP), lalu ekstrak seluruhnya. Jangan menjalankan pemasang dari dalam pratinjau ZIP.
  2. Buka Install.command. Pemasang berjalan di Terminal. Ia mendeteksi chip Intel atau Apple Silicon; memeriksa Python (Tk), lalu menawarkan Homebrew atau tautan unduhan resmi bila belum ada.
  3. Tunggu pemeriksaan. Pemasang mengompilasi dan menjalankan sebuah program uji kecil untuk memastikan hasilnya cocok dengan CPU Mac Anda. Bila gagal, pemasangan berhenti dengan pesan kesalahan.
  4. Jalankan aplikasi dari ~/Applications/Odin Turbo Pascal.app.

Bundel belum ditandatangani Apple. Bila macOS menahan pembukaannya, buka System Settings ▸ Privacy & Security ▸ Open Anyway. Jangan menonaktifkan Gatekeeper secara menyeluruh.

Bila atribut executable hilang saat ZIP diekstrak, jalankan pemasang lewat Terminal: /bin/bash "/lokasi/paket/Install.command".

Windows

  1. Unduh dan ekstrak paket dari github.com/Syamsuddin/ODIN-TURBO-PASCAL (Code ▸ Download ZIP), lalu ekstrak seluruhnya.
  2. Klik dua kali Install.cmd. Pemasang berjalan di PowerShell: memeriksa Windows 10 1809+ 64-bit; mencari Python (Tk), lalu menawarkan winget atau tautan resmi bila belum ada; mengompilasi dan menjalankan program uji dengan kompiler Odin.
  3. Jalankan Odin Turbo Pascal dari menu Start atau pintasan Desktop.

Aplikasi dipasang di %LOCALAPPDATA%\Programs\OdinTurboPascal tanpa memerlukan hak administrator.

Linux

Di Linux, Odin Turbo Pascal dijalankan dari source. Contoh untuk Ubuntu atau Debian:

sudo apt install python3-tk git # IDE (Python + Tk) curl https://sh.rustup.rs -sSf | sh # Rust, sekali saja, untuk membangun odinpc git clone https://github.com/Syamsuddin/ODIN-TURBO-PASCAL.git cd ODIN-TURBO-PASCAL/toolchain cargo build --release # membangun kompiler odinpc cd .. python3 main.py # jalankan IDE

Kompiler, debugger, dan Odin Vision langsung aktif.

Sebagian hal belum diuji di perangkat keras sungguhan, hanya di runner CI dan mesin virtual, antara lain pemasangan di Mac Apple Silicon, peluncuran lewat Finder, Gatekeeper, serta pemasang Windows lengkap. Rincian status pengujian ada di README dan docs/TEST_REPORT.txt.

Sebagian memerlukan unit tertentu, misalnya ClrScr, GotoXY, dan ReadKey ada di unit Crt. Rincian tiap rutin ada di Help ▸ Pascal reference.

Ada dua jenis kesalahan. Kesalahan kompilasi terjadi saat kompiler memeriksa program; tidak ada executable yang dibuat sampai diperbaiki. Kesalahan runtime terjadi saat program yang sudah jadi dijalankan, lalu berhenti dengan Runtime error dan sebuah kode.

Kesalahan Kompilasi yang Sering Muncul

Semua pesan di bawah ini adalah keluaran kompiler Odin yang sebenarnya, diambil dengan sengaja membuat program yang salah. Bentuk pesan: berkas(baris,kolom) Error kode: pesan.

Contoh kesalahan kompilasi dan penyebabnya
Pesan kompilerPenyebab umum
program T; begin WriteLn('a') WriteLn('b'); end.Titik koma terlupa di akhir baris sebelumnya. Periksa akhir baris di atas yang ditunjuk.
program U; begin Jumlah := 5; end.Variabel dipakai tanpa diumumkan di bagian var, atau namanya salah ketik.
program Tp; var N: Integer; begin N := 'sepuluh'; end.Nilai yang diberikan tidak sesuai tipe variabel (di sini String ke Integer).
program R; var N: Integer; begin N := 7 / 2; end.Operator / selalu menghasilkan Real. Untuk hasil bulat pakai div.
program S; var N: Integer; begin N = 5; end.Penugasan ditulis :=, bukan =. Tanda = hanya untuk perbandingan.
program E; var N: Integer; begin N := 5; if N > 3 then WriteLn('besar'); else WriteLn('kecil'); end.Ada titik koma sebelum else yang berpasangan dengan if.
program P; begin WriteLn('Halo); end.Tanda petik penutup string terlupa.
program F; function Dua: Integer; begin Result := 2; end; begin WriteLn(Dua); end.Dalam mode Turbo Pascal tidak ada Result; nilai fungsi diberikan lewat nama fungsi.

Kesalahan Runtime

Program yang lolos kompilasi masih bisa berhenti saat dijalankan. Odin Turbo Pascal menandai baris penyebabnya dengan latar merah (gunakan Search ▸ Find error untuk kembali ke sana). Kode yang sering ditemui:

Kode kesalahan runtime yang umum
KodeArtiContoh penyebab
2Berkas tidak ditemukanReset pada berkas yang belum ada.
103Berkas belum dibukaWrite ke berkas tanpa Rewrite/Reset lebih dulu.
106Masukan tidak sahReadLn angka, tetapi pengguna mengetik huruf.
200Pembagian dengan nolA div 0 atau A / 0.
201Di luar jangkauanIndeks array di luar batas, atau nilai melampaui tipe (range/overflow check).
202Tumpukan (stack) penuhRekursi tanpa kondisi berhenti.
207Operasi pecahan tidak sahSqrt dari bilangan negatif.
216Akses memori tidak sahMembaca atau menulis lewat pointer nil.

Range check dan overflow check aktif secara bawaan di kompiler Odin, sehingga banyak kesalahan tertangkap sebagai kode 201, bukan menghasilkan nilai yang salah secara diam-diam. Biarkan tetap aktif selama belajar.

Seluruh 113 berkas contoh, urut sesuai bab: 90 berkas di File ▸ Examples... (Bab 1–20), 9 di File ▸ Examples - OOP... (Bab 21), dan 14 di File ▸ Examples - Graph... (Bab 22). Angka di kanan adalah halaman tempat listing lengkapnya dibahas.

Istilah penting yang dipakai di buku ini.

Algoritma
Urutan langkah yang jelas dan berhingga untuk menyelesaikan suatu masalah.
Array
Kumpulan data bertipe sama yang disimpan berurutan dan diakses lewat indeks.
Breakpoint
Titik henti yang dipasang pada sebuah baris agar debugger berhenti di situ.
Class
Cetakan objek yang menyatukan field (data) dan method (perilaku); objek dibuat darinya dengan Create.
Constructor
Method khusus yang menyiapkan objek baru, misalnya Create. Pasangannya destructor Destroy.
Debugger
Alat untuk menjalankan program langkah demi langkah dan memeriksa nilai variabel.
Deklarasi
Pengumuman nama (variabel, konstanta, tipe, prosedur) beserta sifatnya sebelum dipakai.
Destructor
Method khusus (Destroy) yang membereskan objek sebelum memorinya dikembalikan; dipanggil lewat Free.
Direktif kompiler
Perintah untuk kompiler, ditulis di antara {$ ... }, misalnya {$R+}.
Ekspresi
Gabungan nilai, variabel, dan operator yang menghasilkan sebuah nilai.
Executable
Program hasil kompilasi yang bisa langsung dijalankan prosesor.
Fungsi
Subprogram yang mengembalikan sebuah nilai.
IDE
Lingkungan pengembangan terpadu: editor, kompiler, dan alat bantu dalam satu aplikasi.
Jendela grafik
Jendela Odin • Graph yang menampilkan piksel program yang memakai unit Graph.
Kata tercadang
Kata yang maknanya sudah ditetapkan bahasa dan tidak boleh dipakai sebagai nama sendiri.
Kode sumber
Teks program yang ditulis manusia, misalnya berkas .pas.
Komentar
Catatan untuk pembaca manusia yang diabaikan kompiler, ditulis di antara { ... }.
Kompiler
Program yang menerjemahkan kode sumber menjadi executable. Odin Turbo Pascal memakai kompiler Odin (odinpc).
Kompilasi
Proses menerjemahkan kode sumber menjadi executable.
Konstanta
Nilai bernama yang tidak berubah selama program berjalan.
Linked list
Rangkaian node yang saling terhubung lewat pointer, bisa tumbuh dan menyusut saat program berjalan.
Method
Prosedur atau fungsi milik sebuah class, dipanggil lewat objek dengan notasi titik.
Objek
Benda yang dibuat dari sebuah class: menyimpan datanya sendiri dan bisa menjalankan method class itu.
Palet
Daftar warna yang menentukan warna nyata setiap nomor warna di layar grafik.
Parameter
Data yang dikirim ke prosedur atau fungsi. Parameter nilai dikirim sebagai salinan, parameter var sebagai acuan.
Pewarisan
Pembuatan class baru (turunan) dari class yang sudah ada (induk); turunan mewarisi semua isi induknya.
Piksel
Titik terkecil gambar di layar grafik, beralamat koordinat (X, Y).
Pointer
Variabel yang menyimpan alamat variabel lain di memori.
Polimorfisme
Kemampuan satu panggilan method virtual menjalankan versi yang berbeda menurut class objeknya.
Prosedur
Subprogram yang mengerjakan tugas tanpa mengembalikan nilai.
Property
Anggota class yang tampak seperti field, tetapi pembacaan dan penulisannya diatur lewat read dan write.
Record
Tipe yang menggabungkan beberapa field bertipe berbeda menjadi satu kesatuan.
Rekursi
Prosedur atau fungsi yang memanggil dirinya sendiri.
Runtime error
Kesalahan yang terjadi saat program berjalan, menyebabkannya berhenti.
Set
Himpunan nilai dari tipe ordinal, dengan operasi gabungan, irisan, dan selisih.
Tipe data
Jenis nilai yang bisa disimpan sebuah variabel, misalnya Integer atau Char.
Unit
Berkas berisi kumpulan deklarasi yang bisa dipakai banyak program lewat uses.
User screen
Layar 80×25 tempat program berjalan dan menampilkan keluaran di Odin Turbo Pascal.
Variabel
Tempat bernama di memori untuk menyimpan nilai yang bisa berubah.
