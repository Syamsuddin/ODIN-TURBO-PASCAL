MAC ALTERNATIVES
Command+N / O / S   New / Open / Save
Command+B           Compile
Command+R           Compile and run
Command+F           Find
Command+W           Close editor
Command+Q           Quit
Command+C / V / X   Copy / Paste / Cut in the editor (Tk native bindings)
Command+Z           Undo in the editor (Tk native binding)

Menu mnemonics: Alt+F/E/S/R/C/D/O/W/H.
Di sebagian pengaturan Mac, tombol Option menghasilkan simbol khusus.
Gunakan klik menu atau pintasan Command bila mnemonic tidak diteruskan Tk.
Tekan Fn bersama F1..F12 jika tombol fungsi dipakai untuk kontrol perangkat.

USER SCREEN
Enter              Input newline
Arrow/Home/End      Terminal navigation
F1..F12, Insert    Diteruskan ke program (ReadKey, Turbo Vision)
Ctrl+C             Interrupt process group
Ctrl+F2            Stop
Alt+F5             Hide User screen
F7/F8              LLDB stepping saat sesi LLDB aktif, selain itu ke program
Copy screen        Menyalin layar teks 80x25 ke clipboard

Ctrl+Insert/Shift+Insert dan Shift+Delete mengikuti binding clipboard Tk pada
platform terkait. Menu Edit tersedia apabila keyboard Mac tidak memiliki Insert.
