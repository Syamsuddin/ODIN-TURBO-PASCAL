KOMPATIBILITAS DAN CAKUPAN VERSI 2.0.0-alpha.1
Lisensi GNU GPL v3 atau yang lebih baru, hak cipta (c) 2026 Syams Ideris.

Implementasi baru dengan penampilan terinspirasi IDE Turbo Pascal era DOS.
Bukan emulasi Borland compiler, bukan replika identik, bukan kompatibilitas
binary DOS, dan tidak berafiliasi dengan Borland.

Komponen                          Status
Editor dan operasi berkas         Diimplementasikan, diuji GUI Linux
Kompilasi FPC mode TP              Diimplementasikan, diuji FPC 3.2.2 Linux
ReadLn, WriteLn                    Diuji melalui binary dan PTY
CRT warna/GotoXY/ClrScr/ReadKey     Diuji melalui program CRT nyata di Linux
Unit Pascal                       Diuji dengan UMATH dan UNITDEMO
LF/CRLF, UTF-8/BOM, CP437          Diuji round-trip
Shell injection via arguments     Tidak memakai shell untuk compile/run
LLDB                              Integrasi tersedia, belum diuji macOS
Mac Intel / Apple Silicon         Jalur installer tersedia, belum diuji hardware
Signing / notarization Apple      Belum tersedia
BGI/Graph DOS                     Tidak diimplementasikan
Interrupt/port/mem DOS            Tidak diemulasi
Debugger Borland terpadu          Tidak diimplementasikan
Watch window, project manager     Tidak tersedia
Terminal truecolor/Unicode lebar  Tidak tersedia
Compiler/runtime dalam bundel     Tidak disertakan, dipasang terpisah

Mode -Mtp mengarahkan FPC mendekati sintaks Turbo Pascal. Perbedaan CPU,
ukuran pointer, ABI, sistem berkas, dan unit tetap berlaku. Jangan menganggap
layout record/binary file DOS atau aritmetika pointer identik pada macOS 64-bit.
Lihat referensi resmi sebelum memindahkan program DOS dengan asumsi 16-bit.

BACKEND COMPILER ODIN (BAWAAN DI MAC INTEL SEJAK 2.0.0-alpha.1)

Backend bawaan versi pengembangan adalah toolchain Odin: compiler odinpc
(Rust) dan runtime library sendiri di rtl/. Free Pascal tetap bisa dipilih
di Options > Compiler, dan dipakai otomatis bila odinpc tidak ditemukan atau
CPU belum didukung. Bagian unit di bawah menjelaskan backend Free Pascal.

Diuji 15 Oktober 2026 pada Mac Intel x86_64 (Darwin 24.6) dengan FPC 3.2.2
sebagai pembanding: kesepuluh contoh, 77 program uji diferensial, dan layar
Crt (jendela, scroll, warna) memberi hasil yang sama. Belum didukung di Apple
Silicon; di sana Odin memakai Free Pascal.

Unit di backend Odin: System, Crt, Dos, Strings, Printer, Objects, dan Odin
Vision (Turbo Vision milik Odin): Drivers, Memory, HistList, Views, Menus,
Validate, Dialogs, App, MsgBox, StdDlg, Editors, Outline. Tipe object TP7
didukung. ColorSel dan TextView belum tersedia; pilih backend Free Pascal
untuk program yang memakainya.
Perbedaan yang disengaja dari FPC dicatat di tests/pascal/DEVIATIONS.md.

Odin Vision mengikuti API Turbo Vision TP7, tetapi tampilan dan beberapa
detailnya milik Odin sendiri (rincian di rtl/vision/SPEC.md):
- Warna palet dirancang sendiri. Tata letak indeks palet sama dengan TP7.
- Ukuran data dialog mengikuti TP7: check box dan radio button 2 byte,
  TMultiCheckBoxes 4 byte, input line MaxLen+1. TListBoxRec 16 byte dan
  parameter TParamText/FormatStr berukuran PtrInt (8 byte). Seperti di FPC,
  record biasa disejajarkan, jadi record data dialog harus packed record.
- Dialog berkas memakai path macOS ('/'), menyembunyikan nama berawalan
  titik, dan menerima nama sampai 255 karakter (datanya PathStr).
- Editor menyimpan akhir baris apa adanya; Enter menyisipkan LF. Undo hanya
  satu langkah, seperti TP. Pasang EditorDialog := StdEditorDialog supaya
  editor bisa bertanya "simpan?".
- Pesan validator, judul MessageBox, dan label tombol bawaan berbahasa
  Inggris, seperti Turbo Vision.
- Ukuran layar mengikuti terminal (di User screen 80x25). Mouse berjalan di
  User screen dan di terminal yang mendukung laporan mouse SGR (xterm,
  Terminal.app, iTerm2). Alt+huruf dikirim sebagai Esc + huruf; di User
  screen macOS, Option dipakai sebagai Alt (tata letak keyboard US). Option
  pada keyboard Mac sungguhan belum diuji, hanya dengan event sintetis.
- Memory tidak membatasi heap: LowMemory selalu False. DosShell menjalankan
  $SHELL.

Executable dari backend Odin memuat runtime library Odin, yang berlisensi
GNU GPL v3 atau yang lebih baru tanpa pengecualian runtime. Bila executable
itu dibagikan, ketentuan GPL berlaku untuk executable tersebut.

UNIT STANDAR TURBO PASCAL 7

Diuji 13 Oktober 2026 pada Mac Intel x86_64 (Darwin 24.6) dengan FPC 3.2.2,
melalui jalur build dan User screen Odin. Untuk Apple Silicon, program uji
hanya dikompilasi silang ke arm64, belum dijalankan pada hardware arm64.

Unit           Status
System         Tersedia otomatis. Rutin string, matematika, Str/Val, berkas
               teks dan bertipe, direktori, ParamStr, New/Dispose, Include/
               Exclude, IOResult, ExitProc diuji berjalan.
Crt            Tersedia. ClrScr, GotoXY, WhereX/WhereY, warna, Window, ClrEol,
               DelLine, Delay, Sound/NoSound, KeyPressed, ReadKey diuji
               berjalan, termasuk F1..F12, Insert, dan panah dengan kode scan TP.
Dos            Tersedia. GetDate/GetTime, GetEnv/EnvCount/EnvStr, FSplit,
               FExpand, FSearch, FindFirst/FindNext, DiskFree/DiskSize,
               GetFAttr, GetFTime/PackTime/UnpackTime, Exec/DosExitCode diuji
               berjalan. DosVersion berisi versi kernel Darwin.
Strings        Tersedia. Rutin PChar (StrPCopy, StrCat, StrPos, StrNew, dst.)
               diuji berjalan.
Objects        Tersedia. TStringCollection dan TBufStream diuji berjalan.
Printer        Tersedia, hanya dikompilasi. Lst diteruskan ke /usr/bin/lpr,
               yaitu printer default macOS.
Turbo Vision   Tersedia sebagai Free Vision: App, Drivers, Views, Menus,

               Alt-X. ColorSel dan TextView tidak tersedia. Odin menambahkan

               Menus milik Apple (univint) terbaca lebih dahulu.
Graph, Graph3  Tidak tersedia (BGI).
Overlay        Tidak tersedia. Hapus uses Overlay dan pemanggilan OvrInit.
WinDos         Tidak tersedia. Gunakan Dos dan Strings.
Turbo3         Tidak tersedia.

Fitur era DOS yang tidak dapat dikompilasi di macOS 64-bit: Mem/MemW/MemL,
Port, absolute $Seg:$Ofs, PrefixSeg, MemAvail/MaxAvail, Test8087, inline(...),
serta Intr/MsDos/Registers. GetIntVec/SetIntVec, Keep, dan procedure interrupt
dapat dikompilasi tetapi tidak berefek: GetIntVec mengembalikan nil dan Keep
tidak menghentikan program. CSeg/DSeg/SSeg bernilai 0. Blok asm memerlukan
{$ASMMODE INTEL}, dan kode 16-bit atau pemanggilan interrupt tetap tidak jalan.

Perbedaan perilaku yang perlu diperhatikan:
- Real berukuran 8 byte (TP: 6 byte). Gunakan tipe Real48 dan Real2Double
  untuk membaca berkas biner berisi Real dari TP.
- Pointer berukuran 8 byte. Integer tetap 2 byte dan LongInt 4 byte di mode TP.
- Round memakai pembulatan ke genap: Round(2.5)=2, Round(-2.5)=-2. Periksa
  program yang bergantung pada pembulatan nilai .5.

Proses build mengarahkan FPC ke -Paarch64 untuk Mac arm64 dan -Px86_64 untuk
Mac Intel, serta memakai SDK dari xcrun jika tersedia. Interpreter launcher
dan source Python sama untuk kedua CPU. Ini berbeda dari binary universal2
yang membundel semua runtime ke satu aplikasi mandiri.

Pemeriksaan akhir di Mac yang masih diperlukan:
1. Jalankan Install.command pada Intel dan Apple Silicon.
2. Pastikan pemeriksaan compile/run native berhasil pada kedua chip.
3. Buka .app dari Finder, tutup, buka kembali, dan uji Open With untuk .pas.
4. Uji Fn+F1..F12, Command shortcuts, clipboard, dialog, dan display Retina.
5. Run INPUT.PAS dan CRTDEMO.PAS, lalu uji LLDB step dan breakpoint.
6. Uji izin Privacy & Security, Gatekeeper, pembaruan app, dan Uninstall.

Hasil Linux tidak menggantikan enam pemeriksaan macOS tersebut.
