TOOLCHAIN ODIN (SATU-SATUNYA COMPILER SESUDAH 2.3.0)

Compiler adalah toolchain Odin: compiler odinpc (Rust, tanpa crate pihak
ketiga) dengan assembler, linker, dan debugger sendiri, serta runtime library
sendiri di rtl/. Target: x86_64-darwin, aarch64-darwin (Mach-O dengan tanda
tangan kode ad-hoc yang diwajibkan macOS di Apple Silicon), x86_64-linux dan
aarch64-linux (ELF dinamis, glibc 2.34 atau lebih baru), x86_64-windows
(PE32+ dengan kernel32 dan UCRT). Di sistem lain (misalnya Windows on ARM)
IDE bisa mengedit tetapi tidak mengompilasi.
Sampai 2.3.0, Free Pascal bisa dipilih sebagai backend alternatif (dengan
mode ObjFPC/Delphi dan Free Vision). Backend itu sudah dicabut. Sejak Tahap
10, odinpc sendiri memahami class gaya Delphi/Free Pascal tanpa mode khusus
(lihat BAHASA: TP7 DENGAN PERLUASAN CLASS). Program ObjFPC/Delphi yang memakai
exception, interface, generic, atau Result tetap tidak bisa dikompilasi.

Diuji 15 Oktober 2026 pada Mac Intel x86_64 (Darwin 24.6) dengan FPC 3.2.2
sebagai pembanding: kesepuluh contoh, 77 program uji diferensial, dan layar
Crt (jendela, scroll, warna) memberi hasil yang sama. Korpus yang sama juga
lulus di VM Ubuntu 24.04 (x86_64, dan aarch64 lewat qemu-user) dan di runner
GitHub Actions untuk macOS 15 Apple Silicon, Ubuntu 24.04 x86_64, dan Ubuntu
24.04 arm64, bersama tes IDE, debugger, dan Odin Vision.
Di runner Windows Server 2025, korpus dibandingkan dengan keluaran Free Pascal
3.2.2 untuk Windows (i386-win32), juga bersama tes IDE, debugger, dan Odin
Vision. Mac Apple Silicon, PC Linux, dan PC Windows fisik belum diuji
langsung.

Di Windows, berkas teks memakai CRLF (WriteLn menulis CRLF seperti di DOS),
path memakai '\' dan huruf drive, Exec memakai _spawnvpe, dan Printer
mencetak lewat notepad /p. Jendela Output IDE memakai ConPTY, dan debugger
berbicara dengan program lewat TCP 127.0.0.1.

Di arm64, prosesor tidak menghentikan program saat operasi real gagal.
Kode hasil kompilasi membaca bendera FPSR sesudah operasi real dan
menghasilkan runtime error 207, 200, atau 205 seperti di x86-64.

Unit Odin: System, Crt, Dos, WinDos, Strings, Printer, Objects, Graph,
Overlay, Math, SysUtils, Classes, Contnrs, dan Odin Vision (Turbo Vision milik
Odin): Drivers, Memory, HistList, Views, Menus, Validate, Dialogs, App,
MsgBox, StdDlg, Editors, Outline, ColorSel, TextView. Tipe object TP7 dan
class (perluasan OOP) didukung.
Ekspektasi uji dibuat dengan Free Pascal 3.2.2 sebagai pembanding sampai
2.3.0; perbedaan yang disengaja dicatat di tests/pascal/DEVIATIONS.md.

Odin Vision mengikuti API Turbo Vision TP7, tetapi tampilan dan beberapa
detailnya milik Odin sendiri (rincian di rtl/vision/SPEC.md):
- Warna palet dirancang sendiri. Tata letak indeks palet sama dengan TP7.
- Ukuran data dialog mengikuti TP7: check box dan radio button 2 byte,
  TMultiCheckBoxes 4 byte, input line MaxLen+1. TListBoxRec 16 byte dan
  parameter TParamText/FormatStr berukuran PtrInt (8 byte). Record biasa
  disejajarkan, jadi record data dialog harus packed record.
- Dialog berkas memakai path macOS ('/'), menyembunyikan nama berawalan
  titik, dan menerima nama sampai 255 karakter (datanya PathStr).
- Editor menyimpan akhir baris apa adanya; Enter menyisipkan LF. Undo hanya
  satu langkah, seperti TP. Pasang EditorDialog := StdEditorDialog supaya
  editor bisa bertanya "simpan?".
- Pesan validator, judul MessageBox, dan label tombol bawaan berbahasa
  Inggris, seperti Turbo Vision.
- Ukuran layar mengikuti terminal (di jendela Output 80x25). Mouse berjalan di
  jendela Output dan di terminal yang mendukung laporan mouse SGR (xterm,
  Terminal.app, iTerm2). Alt+huruf dikirim sebagai Esc + huruf; di User
  screen macOS, Option dipakai sebagai Alt (tata letak keyboard US). Option
  pada keyboard Mac sungguhan belum diuji, hanya dengan event sintetis.
- Memory tidak membatasi heap: LowMemory selalu False. DosShell menjalankan
  $SHELL.
- ColorSel dan TextView mengikuti API TP7, termasuk daftar item standar TV2
  (DesktopColorItems, MenuColorItems, DialogColorItems, WindowColorItems),
  ColorIndexes, dan registrasi stream ColorSel. TTerminal memakai buffer
  melingkar: bila penuh, baris teratas dibuang. WriteLn ke berkas yang dipasang
  dengan AssignDevice langsung tampil di jendelanya; CR dibuang dan Tab menjadi
  kelipatan 8 kolom. Tampilan dialog warna rancangan Odin sendiri.

Executable hasil Odin memuat runtime library Odin, yang berlisensi
GNU GPL v3 atau yang lebih baru tanpa pengecualian runtime. Bila executable
itu dibagikan, ketentuan GPL berlaku untuk executable tersebut.

BAHASA: TP7 DENGAN PERLUASAN CLASS

Secara bawaan bahasanya Turbo Pascal 7. Di atasnya Odin menambah OOP
berbasis class seperti Delphi dan Free Pascal. Perluasan ini tidak memerlukan
direktif atau mode, dan tidak menambah kata tercadang: class, property,
protected, published, strict, override, abstract, reintroduce, overload,
dynamic, is, dan as hanya bermakna di tempat yang tidak mungkin berisi nama
dalam program TP7. Program TP7 yang memakai kata-kata itu sebagai nama tetap
dikompilasi. Satu pengecualian: alias "T = Class;" ke tipe bernama Class kini
dibaca sebagai deklarasi forward sebuah class.

Didukung:
- class, class(Induk), deklarasi forward "TFoo = class;", dan "class of TFoo"
  (rujukan class). Class tanpa induk menurun dari System.TObject.
- Bagian private, protected, public, published, strict private, dan
  strict protected. Private dan protected terlihat di seluruh unit atau
  program yang mendeklarasikannya, seperti di Delphi.
- Field, method, constructor, destructor, class var, class procedure dan
  class function (juga virtual), serta Self.
- virtual, dynamic (sama dengan virtual), override, abstract, reintroduce,
  inherited dengan nama, dan inherited tanpa nama (memanggil method yang
  sama milik induk dengan argumen yang sama).
- Constructor virtual yang dipanggil lewat rujukan class (C.Create).
- property yang membaca dan menulis lewat field, class var, atau method,
  property hanya-baca, property larik ("Items[I: Integer]"), dan property
  larik default ("List[I]").
- overload untuk method dan constructor. Versi yang dipilih adalah yang
  paling cocok dengan tipe argumen.
- Operator is dan as, typecast antara class, Pointer, dan integer, with pada
  instance, nil, Assigned, serta = dan <> antar-rujukan.
- TObject: Create, Destroy, Free, ClassName, ClassNameIs, ClassParent,
  ClassType, InstanceSize, InheritsFrom, dan ToString.

Belum termasuk: exception (try/except/finally/raise), interface, generic,
pointer method (procedure of object), Result, parameter bawaan, overload
untuk rutin biasa, class helper, tipe bersarang, class constructor, serta
sealed dan final. Tanpa exception, salah pakai class menjadi runtime error:
211 (method abstract dipanggil), 219 (as gagal), dan 216 (akses lewat
rujukan nil).

Program yang memakai uses Objects punya dua TObject: tipe object TP7 milik
Objects dan class akar milik System. Class tanpa induk tetap menurun dari
class akar, dan nama itu bisa ditulis System.TObject.

UNIT STANDAR TURBO PASCAL 7

Unit           Status
System         Tersedia otomatis. Rutin string, matematika, Str/Val, berkas
               teks dan bertipe, direktori, ParamStr, New/Dispose, Include/
               Exclude, IOResult, ExitProc.
Crt            Tersedia. ClrScr, GotoXY, WhereX/WhereY, warna, Window, ClrEol,
               DelLine, Delay, Sound/NoSound, KeyPressed, ReadKey, termasuk
               F1..F12, Insert, dan panah dengan kode scan TP.
Dos            Tersedia. GetDate/GetTime, GetEnv/EnvCount/EnvStr, FSplit,
               FExpand, FSearch, FindFirst/FindNext, DiskFree/DiskSize,
               GetFAttr, GetFTime/PackTime/UnpackTime, Exec/DosExitCode.
               DosVersion berisi versi kernel sistem.
Strings        Tersedia. Rutin PChar (StrPCopy, StrCat, StrPos, StrNew, dst.).
Objects        Tersedia. Koleksi, stream, dan RegisterType.
Printer        Tersedia. Lst diteruskan ke /usr/bin/lpr (printer default
               macOS), lpr di Linux, atau notepad /p di Windows.
Turbo Vision   Tersedia sebagai Odin Vision (lihat di atas), termasuk ColorSel
               dan TextView.
WinDos         Tersedia. Dos dengan PChar (FindFirst, FileSplit, FileExpand,
               GetCurDir, GetArgStr, GetEnvVar, ...), diteruskan ke Dos. Tanpa
               Intr, MsDos, TRegisters, GetIntVec, dan SetIntVec. Batas
               fsPathName, fsDirectory, fsFileName, dan fsExtension di sini
               259 dan 255 (bukan 79, 67, 8, 4), TSearchRec.Name menampung
               255 karakter, dan DiskFree/DiskSize mengembalikan Int64.
Graph          Tersedia: antarmuka BGI TP7 (InitGraph, Line, Circle, Arc,
               Ellipse, PieSlice, Bar, Bar3D, FillPoly, FloodFill, pola
               isian, gaya garis, palet, OutText, GetImage/PutImage, viewport,
               halaman). Semua mode driver CGA, MCGA, EGA, EGA64, EGAMono,
               IBM8514, HercMono, ATT400, VGA, dan PC3270 dikenali dengan
               resolusi aslinya. Gambar disimpan di framebuffer di memori
               (satu byte per piksel); GetPixel, GetImage, dan PutImage
               memberi hasil piksel demi piksel. Perbedaan dengan BGI Borland:
               - Tidak ada berkas driver (.BGI) dan font (.CHR): parameter
                 Dir InitGraph diabaikan, RegisterBGIdriver dan
                 InstallUserDriver hanya mencatat, dan semua font memakai font
                 bitmap 8 x 8 yang diskalakan menurut CharSize. TextWidth dan
                 TextHeight bukan ukuran font stroke aslinya.
               - Di IDE, program yang memakai Graph membuka jendela grafik
                 dengan piksel sebenarnya: framebuffer dikirim lewat soket
                 TCP 127.0.0.1 (ODIN_GRAPH_PORT, dijaga token
                 ODIN_GRAPH_TOKEN) hanya untuk baris yang berubah, dan tombol
                 yang diketik di jendela diteruskan ke ReadKey. Jendelanya
                 tetap dengan gambar terakhir bila program selesai tanpa
                 CloseGraph, dan hilang saat CloseGraph. Setelan graph_window
                 = false di settings.json mematikannya.
               - Tanpa jendela (terminal biasa, atau program yang dijalankan di
                 luar IDE), tampilannya pratinjau kasar: tiap sel memuat dua
                 subpiksel dengan 16 warna CRT (sekitar 80 x 50 titik di
                 80 x 25) dan gambar diskalakan dengan perbandingan
                 lebar-tinggi yang benar. Teks BGI ditampilkan sebagai
                 karakter asli; teks vertikal dan teks yang sudah tertimpa
                 tampil sebagai blok. Layar digambar ulang ketika program
                 menunggu lewat Crt (ReadKey, KeyPressed, Delay), tiap 0,1
                 detik saat menggambar, dan saat program selesai.
               - Keluaran yang dialihkan ke berkas tanpa jendela tidak
                 menampilkan apa-apa.
               - SetRGBPalette dipetakan ke warna CRT terdekat di layar; nilai
                 0..63 dianggap DAC VGA, yang lebih besar dianggap 8 bit.
               - Galat GraphResult sama dengan BGI; pesan GraphErrorMsg dalam
                 bahasa Inggris.
               Pakai Crt (ReadKey) untuk menahan gambar sebelum CloseGraph.
Overlay        Tersedia sebagai antarmuka saja: semua kode ada di memori, jadi
               OvrInit selalu berhasil, OvrInitEMS melapor ovrNoEMSDriver,
               dan pengaturan buffer hanya dicatat. Direktif {$O ...}
               diabaikan.
Math           Bukan unit TP7 tetapi umum di Free Pascal/Delphi: trigonometri
               dan hiperbolik, Power, IntPower, Log10, Log2, Ceil, Floor,
               RoundTo, Min/Max, statistik larik, fungsi keuangan. Rutin biasa
               tidak bisa di-overload: Min/Max hanya Int64 (MinF/MaxF untuk
               Real), begitu juga InRange, EnsureRange, CompareValue (akhiran
               F), dan SumInt untuk Integer. Galat domain = runtime error 207.
SysUtils       Bukan unit TP7. Subset kecil: IntToStr, IntToHex, StrToInt,
               StrToFloat, FloatToStr, FloatToStrF, FormatFloat, UpperCase,
               Trim, StringReplace, nama berkas, FileExists dan sejenisnya,
               TDateTime (EncodeDate, FormatDateTime, ...), Sleep,
               FreeAndNil. Tidak ada exception (galat konversi = runtime
               error 106; pakai TryStrToInt atau StrToIntDef), Format (butuh
               array of const), parameter bawaan, maupun overload.
Classes        Bukan unit TP7. Subset Classes Free Pascal/Delphi yang ditulis
               dengan class: TList (daftar pointer, Sort dengan fungsi
               pembanding) dan TStringList (Sorted, Find, IndexOf,
               CaseSensitive, Objects, LoadFromFile, SaveToFile). Indeks di
               luar daftar = runtime error 201 (di FPC: EListError). Tanpa
               Text dan CommaText (String tetap 255 karakter).
Contnrs        Bukan unit TP7. TObjectList: daftar objek yang membebaskan
               objeknya sendiri bila OwnsObjects (bawaan TRUE).
Graph3, Turbo3 Tidak tersedia.
Turbo3         Tidak tersedia.

Fitur era DOS yang tidak dapat dikompilasi di sistem 64-bit: Mem/MemW/MemL,
Port, absolute $Seg:$Ofs, PrefixSeg, MemAvail/MaxAvail, Test8087, inline(...),
procedure interrupt, serta Intr/MsDos/Registers. Blok asm belum didukung.
GetIntVec/SetIntVec dan Keep dapat dikompilasi tetapi tidak berefek:
GetIntVec mengembalikan nil dan Keep tidak menghentikan program. CSeg/DSeg/
SSeg bernilai 0.

Perbedaan perilaku yang perlu diperhatikan:
- Real berukuran 8 byte (TP: 6 byte), dan Real48 tidak tersedia. Berkas biner
  berisi Real dari TP perlu dikonversi lebih dahulu.
- Pointer berukuran 8 byte. Integer tetap 2 byte dan LongInt 4 byte.
- Round memakai pembulatan ke genap: Round(2.5)=2, Round(-2.5)=-2. Periksa
  program yang bergantung pada pembulatan nilai .5.

Bundel macOS membawa odinpc universal (x86_64 dan arm64); odinpc membuat
program untuk CPU Mac yang menjalankannya. Interpreter launcher dan source
Python sama untuk kedua CPU. Ini berbeda dari binary universal2 yang
membundel semua runtime ke satu aplikasi mandiri.

Pemeriksaan akhir di Mac yang masih diperlukan, di Mac bersih tanpa Free
Pascal dan tanpa Xcode Command Line Tools:
1. Jalankan Install.command pada Intel dan Apple Silicon.
2. Pastikan pemeriksaan compile/run native dengan odinpc berhasil pada kedua
   chip.
3. Buka .app dari Finder, tutup, buka kembali, dan uji Open With untuk .pas.
4. Uji Fn+F1..F12, Command shortcuts, clipboard, dialog, dan display Retina.
5. Run bab04_02_read_readln.pas dan bab19_02_unit_crt.pas, uji debugger
   (breakpoint, Watch, Call stack), lalu demo Odin Vision.
6. Uji izin Privacy & Security, Gatekeeper, pembaruan app, dan Uninstall.

Hasil Linux dan runner CI tidak menggantikan enam pemeriksaan macOS tersebut.
